# 产品场景与验收入口

场景文档描述用户目标、自然表达、系统分工、失败恢复和通过条件；目标图不等于当前能力。当前进展见[项目状态](../docs/项目状态.md)，第一阶段冻结范围见[版本说明](../docs/releases/001-MVP1第一阶段里程碑.md)。

| 场景 | 验证差异 | 当前边界 |
| --- | --- | --- |
| [销售合同跨员工交接](sales-contract-handoff/合同场景设计.md) | 文件版本、团队协作、正式审批、跨员工退回与续办 | 本轮合成合同已走通 Office 原件提交、退回、R2 双人复核、最终通知续看及下载；仅证明内部复核闭环，不代表已签署、下单或其他历史合同通过 |
| [销售订单闭环](sales-order-handoff/销售订单闭环场景设计.md) | 员工签署登记、结构化下单条件、预收独立确认、合同转订单和原生审批 | 复用已内部复核的合成合同；个人办理连接与规则实施中，尚未完成本场景业务验收；不新增这些 Weave 团队，项目与后半回款后置 |
| [线索转商机](lead-to-opportunity/线索转商机场景设计.md) | 指定业务对象、关联记录创建、授权与防重复 | 销售 Pi 授权转化和 Forge 本人读回已走通；另用新线索验证 Forge 同输入重放不多建客户或商机，Weave 派发恢复仍待验 |
| [报价核算与调整](quotation-review/报价核算与调整场景设计.md) | 结构化明细、确定性计算、试算与保存、并发修改 | 两行草稿由销售创建，Pi/团队核对并授权改单价至 ¥900，Forge 重开读回 ¥2,100；历史失败消息标题与并发/未知结果仍待处理 |

上述场景分别覆盖合同跨员工接力、销售订单、线索转化和报价明细。每份文档开头区分当前实走与历史失败，未通过项汇总在[问题清单](../docs/plans/问题清单.md)。当前先收束销售订单闭环，KP2 项目交接及后半链路另行展开。

开发联调及后续演示的账号、ObjectStack 岗位、业务角色、权限集与业务边界统一维护在[演示账号与 ObjectStack 配置](演示账号与ObjectStack配置.md)。测试密码只保存在本机被忽略的文件，场景正文不重复保存；流程依据见[通用项目与数字教育流程](../docs/architecture/订单到回款业务流程.md)。
