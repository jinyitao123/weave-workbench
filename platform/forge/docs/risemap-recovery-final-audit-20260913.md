# RISEMAP 产品结构复刻挽回最终审查

审查日期：2026-09-12
Forge 基线：`main`，提交 `0d692bc` 及本轮完整浏览器链证据
审查范围：菜单与信息架构、当前主线盘点、委外样板的产品/工程/质量门禁及推广边界。

## 最终判定

当前结果是：**菜单与信息架构已按 RISEMAP 证据完成第一轮重整；委外样板已在同一 SQLite 上完成从浏览器建单、库存准备到发料、签收、回厂入库、对账和应付生成的连续浏览器链，达到 Forge 本地受控样板门槛，但尚未达到 RISEMAP 等价复刻或独立业务验收通过。**

因此下一步仍只修补委外，不自动迁移采购、生产、销售或财务其他模块。

## 仍待证明的门禁

1. 使用同一干净 SQLite，由真实多角色账号连续完成业务员、仓库、质量、财务四个岗位的完整链路；当前只证明单管理员下从已有订单/库存前置材料开始的连续浏览器链。
2. 当前样本已完成从订单建单和期初库存准备开始的同库停服重启 API 与新浏览器页回读；期初入库属于样板准备动作，尚不能外推为采购到货或真实仓储业务闭环。
3. 用真实多角色账号证明待办分派、动作权限、数据范围和不可越权阻断。
4. 以保存的 RISEMAP 当前页面和可成功办理材料复核签收、回厂、四类 NCR、退料、供应商确认、差异结算和付款关系。
5. 取得独立业务验收人的正常路径、异常路径和推广签字；没有签字时只能称为工程样板。

## 停止规则

出现来源丢失、状态可绕过、异常仍可结算、金额重复、页面无法进入下一岗位、同库重启结果不一致或 RISEMAP 事实与实现冲突时，停止新增功能，先修正产品语义、持久化边界或证据记录。
