# 到货登记页面合同

日期：2026-09-16

## 页面职责与原型

- RISEMAP：`https://risemap.cn/inventory/arrival`、`/inventory/arrival/new`；Forge：`page_purchase_arrival_workspace`。
- 岗位：仓库收货员；主单据：到货登记及明细；主原型：任务执行型，参考 `task_workspace` 与 `ForgePageHeader`。
- 首屏顺序：页头与登记动作 → 下一步入口 → 订单/物料视图 → 搜索筛选 → 列表；详情按状态提供提交待检。
- 下一步：待检验库存。

## RISEMAP 当前事实

- 列表含订单明细/物料明细、新建、导出、导入导出任务、刷新、搜索、状态和类型筛选。
- 新建采购到货要求供应商和采购订单，物料行由订单带出；包含日期、联系人、电话、承运商、物流单号、备注和附件；可保存草稿或提交检验。

## Forge 实现与未决项

- Forge 由到货通知带出订单物料，支持数量、仓库、库位、批次、保存草稿、提交待检及逐物料生成待检记录。
- 附件服务尚未接入，因此不显示无结果上传按钮；其他到货与退货分支不在本页面冒充已复刻。

## 验收材料

- 使用同一采购订单完成通知 → 草稿 → 提交待检，并验证超量与缺仓库阻断、状态回读和窄屏布局。
