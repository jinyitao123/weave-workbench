# 采购退换货出库页面合同

日期：2026-09-15

## RISEMAP 当前事实

- 入口：供应链 → 出库管理 → 采购退换货出库，地址 `/inventory/outbound/purchase-returns`。
- 页面无独立新建入口，包含刷新及退货单号、采购单号、供应商搜索。
- 列为退货单号、供应商、退货地址、退货金额、出库进度、状态、日期、操作，默认每页 20 条。
- 当前租户为空，空态为“暂无待建单的采购退货单”；有数据行操作待同材料复核。

## Forge 当前实现

- 入口：`/_console/apps/forge/page/page_purchase_return_outbounds`。
- 读取真实采购退换货主单和明细，聚合退货数量与已出库数量，展示来源采购订单、供应商、金额和进度。
- 仓库已确认的单据显示“办理出库”，其余状态显示“查看”，统一返回采购退换货主单继续办理。
- 出库动作由采购退换货主链执行，重复出库在服务端状态校验处阻断，不在列表页增加无来源的新建动作。

## 本轮验收

- RISEMAP 与 Forge 内置浏览器实时核对列、搜索、空态语义和分页。
- Forge 页面搜索 `UI-RET-20260915-001`，回读供应商退货仓、¥1,360.00、`0.2 / 0.2`、100% 和已完成，并进入来源采购退换货页。
- API 回读采购订单、供应商、退货明细和逐行库存流水；重复出库被阻断且未增加流水。
- 同一 SQLite 完整停服重启后，API 与浏览器继续回读上述结果。

RISEMAP 当前无可办理数据，因此同材料页面出库动作仍标记为待复核。
