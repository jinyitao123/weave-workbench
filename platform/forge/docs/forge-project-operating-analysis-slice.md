# Forge 项目经营分析切片

更新于 2026-09-10。该切片把已结算项目的合同收入、生产材料成本、利润、进度、实际回款和结算快照放在同一页面，支持全部项目与单个项目两种视图。页面指标直接读取持久业务对象，不复制一套不可追溯的报表数字。

## 指标口径

- 营收：已结算项目取项目结算快照的合同金额；没有结算快照时取项目合同金额，仍为空时才取预计营收。
- 成本：已结算项目取结算快照的生产材料成本；没有结算快照时取项目当前总成本。
- 利润：营收减成本；利润率为利润除以营收。
- 已回款：项目由审核通过的收款核销累计得到的已回款金额；回款率为已回款除以营收。
- 所有项目明细显示项目状态、进度、营收、成本、利润、利润率、已回款、回款率和结算快照编号。

## RISEMAP 对照与边界

RISEMAP 项目分析中心当前同一项目显示营收 `243200`、成本 `0`、利润 `243200`、已回款 `0`，并提供营收成本利润对比、成本构成、费用流向和利润率排名；项目统计页显示相同经营指标及进度、状态和贡献排行。该差异来自 RISEMAP 当前没有已归集成本和回款，不能与 Forge 的已结算状态直接作数值一致性结论。RISEMAP 的利润说明为收入减对应成本及费用，回款说明为筛选范围内有效回款金额合计。
