# 待检验库存页面合同

日期：2026-09-16

## 页面职责与原型

- RISEMAP：`https://risemap.cn/inventory/pending-inspection`；Forge：`page_pending_inspection_workspace`。
- 岗位：来料质检员；主单据：逐物料待检记录；主原型：任务执行型，参考 `task_workspace` 与 `ForgePageHeader`。
- 首屏顺序：页头与下一步 → 搜索筛选 → 待检明细 → 分页；主动作是选择检验方式后生成一张检验单。
- 下一步：检验单。

## RISEMAP 当前事实

- 每个物料一条待检记录；列为待检单号、物料信息、到货数量、单位、批次、供应商/客户、采购合同、到货日期、状态、关联检验单、结果、操作。
- 提供搜索、状态筛选、导出、导入导出任务和刷新；当前租户为空。

## Forge 实现与未决项

- Forge 到货提交后逐物料生成待检记录；未生成检验单时可选择全检或抽检并确认生成，已生成后只能查看关联单。
- 免检的规则来源依赖检验方案；当前页面不自行推断免检。

## 验收材料

- 验证一条待检记录生成一张检验单、重复生成阻断、关联单回读、筛选与窄屏布局。
