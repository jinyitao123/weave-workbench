# 出库单列表页面合同（2026-09-15）

## RISEMAP 当前事实

- 入口：供应链 → 出库管理 → 出库单列表，URL 为 `https://risemap.cn/inventory/outbound`。
- 标题为“出库单列表”，说明为“管理所有出库单和待出库发货单”。
- 工具栏包含打印条码、导出、刷新；未选择单据时打印条码禁用。
- 筛选包含全文搜索、业务类型、状态。业务类型当前显示销售出库、生产领料、采购退货、其他出库、生产出库、委外出库、销售直接出库；状态当前显示待出库、已出库、已签收。
- 列为出库单号、关联单号、销售单号、客户单号、往来单位、物料明细、仓库、出库日期、状态、物流信息、收入确认、操作员、操作，并带多选框和 20 条分页。
- 当前试用租户列表为空，尚不能用同一材料核对有数据时的详情动作和签收流转。

## Forge 实现与决策

- `page_sales_outbound_list` 改为统一出库单列表，不再只展示销售出库。
- 已过账单据从库存流水按来源单据聚合，覆盖销售直接出库、生产领料、采购退货、其他出库和委外出库；已审批但未过账的其他出库、采购退货和委外出库显示为待出库。
- 列、搜索、业务类型、状态、分页、选择、条码预览、导出和刷新按当前 RISEMAP 首屏合同实现。
- “查看/办理”跳回真实来源业务页，不提供无结果按钮。收入确认只对销售出库显示，其余业务显示 `—`。
- Forge 将来源库存流水作为已出库判断依据；这是现有账实一致性实现，不把 RISEMAP 空租户状态推断成其后端规则。

## 验收材料

- 页面：RISEMAP `/inventory/outbound` 与 Forge `page_sales_outbound_list`。
- API：`pnpm acceptance:outbound-list-readback`。
- 持久性：同一 `supply-chain-pages.sqlite` 完整停服重启后再次运行 API，并在 Forge 页面回读来源、数量和状态。
- 工程门禁：`pnpm typecheck`、`pnpm validate`、`pnpm build`。
