## Forge 页面行为

- 项目中心进入当前项目详情，再进入 `page_project_plan_risemap` 办理计划。
- 页面保留 RISEMAP 计划参考和 Forge 当前计划两个数据层。参考区从 `forge_project_plan_evidence` 读取，不写入 Forge 执行记录。
- 当前计划支持添加阶段、里程碑和任务；支持列表、甘特图和进度视图；支持编辑进度、填日报和删除符合条件的工作项。
- 计划表显示名称、类型、负责人、计划开始、计划结束、工期、前置任务、权重、完成进度、状态、交付物和操作。
- 任务或里程碑删除前显示标准确认弹窗，明确对象、不可恢复影响和系统阻断条件。
- 将工作项状态改为“已取消”时，先填写进度状态，再显示影响确认弹窗；只有点击“确认取消”才提交。
- 项目暂停和终止先填写原因，再显示第二层影响确认；第二层明确项目编号、项目名称、业务影响和原因。
- 阶段有下级工作项、工作项已完成、已有日报或仍被其他任务引用时，服务端阻止删除。
- 套用模板和保存为模板入口可用。Forge 已建立计划模板对象，支持保存当前计划结构、读取模板并在空计划中套用；已有工作项的计划会阻止套用。RISEMAP 当前模板办理路径仍待同材料复核。

## Forge 产品决策

RISEMAP 当前页面是复刻基线。Forge 对删除、终止、暂停和取消工作项增加第二层确认，属于产品安全决策，不描述为 RISEMAP 已观察规则。

Forge 当前执行数据与 RISEMAP 当前事实分层展示。Forge 中“确认项目范围与边界”为 50%、进行中，当前计划和项目执行进度为 63%；RISEMAP 当前同名任务为 0%、已延期，阶段进度为 83%。该差异保留为待同材料办理项，不能写成已对齐。

## 验收条件

- 每轮先实时打开 RISEMAP 当前页面，再打开 Forge 对应页面。
- 使用同一业务材料逐项核对入口、字段、状态、弹窗、阻断、反馈、来源关系和下一步。
- 正常路径与关键阻断均通过 API 验收。
- 使用同一 SQLite 完整停服重启，页面和 API 均能回读结果。
- 每次元数据修改运行 `pnpm typecheck`、`pnpm validate`、`pnpm build`。
- 模板持久化、同名任务进度差异和 RISEMAP 当前数据不足的路径解决前，项目计划块保持“部分通过”，不得进入下一功能块并宣称整体完成。
