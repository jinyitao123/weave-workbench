# Forge 询价管理页面合同（2026-09-16）

## 页面证据与职责

- RISEMAP 当前入口：供应链 → 采购管理 → 询价管理，`https://risemap.cn/purchase/rfq`。
- Forge 入口：`/_console/apps/forge/page/page_purchase_inquiry`。
- 岗位：采购员；主单据：询价单；下一步：采购订单。
- 主原型：任务执行型，参考 `project-task-workspace.page.ts`；首屏依次为标题与动作、五阶段流程、搜索筛选、询价列表，进入单据后办理物料、邀请供应商、登记报价、比价和转采购单。

## RISEMAP 当前已观察事实

- 列表说明为“发起询价、收集报价、多供应商比价择优”。
- 阶段依次为创建询价（待发布）、发布询价（生成链接/设期限）、收集报价（报价收集中）、确认比价（已完成比价）、转采购单（已转采购单）；任意阶段可手动关闭。
- 列为询价单号、标题、来源、负责采购、供应商报价、物料数、状态、截止日期、操作；有范围和状态筛选、导出、导入/导出任务和刷新。
- 新建先选择手动创建、从采购需求创建、从销售合同创建。手动创建填写询价标题、可选关联项目、必填截止日期，确认后进入物料编辑页；采购需求和销售合同路径会自动带入物料清单。
- 当前试用数据为 0 条，因此发布链接的外部访问样式、供应商端填写页和关闭阻断仍缺少可办理数据验证。

## Forge 本轮处理结论

- 实现三种创建来源；采购申请与销售合同复制来源物料并保留行级来源。
- 草稿可新增/删除物料并邀请供应商；发布前阻断无物料、无供应商或截止日期已过。
- 已发布询价可逐供应商登记逐物料报价；比价表展示总额、交期、有效期、付款条件并选择中选报价。
- 中选后填写目标仓库、预计到货日期和付款条件，生成采购订单与明细并回写来源询价。
- 邀请供应商只展示已启用且已审批记录；转单生成明细后调用订单提交动作，汇总物料数、数量和金额并进入待审核，而不是留下不可继续办理的草稿。
- 转单失败会回滚本次新建的订单、明细和已变化待办；金额以四位小数序列化，避免二进制小数触发精度阻断。
- 关闭使用标准确认弹窗并保留历史数据；已转采购单不可关闭。
