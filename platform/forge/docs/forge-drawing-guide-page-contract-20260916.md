# Forge 图纸管理上手指南页面合同（2026-09-16）

## 页面职责与原型

- RISEMAP：`https://risemap.cn/drawing/guide`；Forge：`page_drawing_guide`。
- 岗位：设计/工艺、审核/会审、文控管理员、使用部门。
- 主原型：配置型，参考 `page_project_timesheet_cost` 的紧凑标题、范围切换和任务区，复用 `ForgePageHeader` 与共享按钮语言。
- 首屏顺序：标题与图纸总览入口 → 角色视角与学习进度 → 六阶段生命周期 → 指南目录与搜索 → 当前指南正文和真实办理入口。
- 页面只解释已存在的图纸业务并导航到真实页面，不在指南内代替图号、评审、发布、变更或发放动作。

## RISEMAP 当前实时事实

- 标题“图纸管理上手指南”，说明按角色完成建档、会审、发布、变更和受控发放。
- 角色为设计/工艺、审核/会审、文控管理员、使用部门；切换角色会改变角色说明、学习进度、关注阶段和指南目录数量。
- 完整流程为图号建档、版本提交、会审审批、图纸发布、变更执行、发放追溯六阶段；不属于当前角色的阶段不可选择。
- 当前文章显示阶段、分类、标题、摘要、时长、适用场景、开始前确认、操作步骤、完成标志、常见阻塞与处理。
- 搜索只作用于当前角色的指南内容；“标记已掌握”更新学习进度；“打开图纸总览”进入真实业务页。
- 当前线上指南是说明与导航页面，本轮未在 RISEMAP 写入图纸业务数据。

## Forge 处理结论

- 从 `supply-production-routing.page.ts` 的通用来源卡片中拆出独立 `drawing-guide.page.ts`，不再把图号、评审、发布对象的前八条记录冒充指南。
- 只为当前角色实际关注的阶段渲染按钮；不相关阶段显示为说明状态，避免灰色假按钮。
- 角色、阶段、目录和搜索均真实筛选指南；标记已掌握写入浏览器本地学习偏好并可再次取消，刷新后回读。
- 每篇指南的主动作进入对应图号档案、评审、发布、变更、发放、关联查询或客户图纸页面；页头“打开图纸总览”进入真实总览。

## 证据边界

- RISEMAP 当前指南内容已实时核对，但学习状态是否跨设备同步、角色与权限是否联动仍未验证。
- Forge 学习进度属于当前浏览器偏好，不冒充服务器业务状态；图纸单据的业务正确性由各职责页单独验收。
- 页面保持 `review_required`，直到桌面、窄屏截图与独立复核完成。
