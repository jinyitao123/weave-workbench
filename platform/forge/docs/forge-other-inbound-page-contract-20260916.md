# Forge 其他入库页面合同（2026-09-16）

## 页面职责与主原型

- RISEMAP：`/inventory/inbound/other`、`/inventory/inbound/new` 切换“其他入库”；Forge：`page_other_inbounds`。
- 岗位：仓库经办、库存审批人；主单据：其他入库单及物料明细。
- 主原型：任务执行型，复用 `ForgePageHeader`、共享选择/日期/状态/确认弹窗；首屏按标题动作、状态步骤、摘要、基本信息、物料明细排列。
- 主动作：新建、保存草稿、提交审批、审批通过、执行入库。执行入库增加正式库存并生成逐物料流水；取消必须二次确认且不能回滚已形成的流水。

## RISEMAP 实时事实

- 列表标题为“入库单”，工具栏包含新建其他入库、打印条码、导出、刷新；打印以勾选记录为对象。
- 列为勾选、入库单号、类型、来源、入库类型、批次号、供应商/客户、仓库、入库日期、含税金额、状态、创建人、操作；当前租户 0 条记录。
- 新建页提供采购/其他/退货三类切换。其他入库基本信息包含日期、必填入库类型、可选往来单位（客户/供应商）、到货原因；物料区包含下载模板、Excel 导入、导入任务、添加物料；备注与附件位于末尾。
- 未填写必填入库类型和物料时，RISEMAP 阻断提交并显示字段/页面错误。本轮线上无可办理数据，未完成同材料提交审批及执行入库。

## Forge 处理结论

- 列表勾选后才启用打印，标准弹窗只展示所选记录；筛选、导出、刷新、分页和详情均可操作。
- 新建页补齐客户/供应商切换、往来单位、到货原因、摘要和状态步骤；字段持久化到 `forge_other_inbound`。
- 提供可实际下载、导入、逐行校验的 CSV 模板。RISEMAP 异步 Excel 任务与附件上传缺少可验证 Forge 文件服务，页面明确说明，不放置假按钮。
- 详情按状态提供提交、审批、执行入库和取消；库存余额与流水由 Action 更新，页面不能直接改库存。
