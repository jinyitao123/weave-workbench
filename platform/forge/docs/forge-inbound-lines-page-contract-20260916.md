# Forge 入库明细页面合同（2026-09-16）

## 页面职责与主原型

- RISEMAP：`/inventory/inbound/details`；Forge：`page_inbound_lines`。
- 岗位：仓库复核、采购/生产/委外追溯人员；主原型：分析型，参考工时管理的高密度筛选、明细表和分页。
- 页面只统一查询采购、生产、其他、期初、委外五类已持久化明细，不在聚合表直接改业务状态。

## RISEMAP 实时事实

- 标题“入库明细”，说明“管理所有入库单据”，工具栏有导出、刷新。
- 筛选为入库单号、物料编码/名称/规格、状态、业务类型、开始/结束日期。
- 表格包含勾选、序号、单据日期、入库单号、业务类型、仓库、供应商/对方、制单人、编码、物料名称、规格、型号、单位、数量、含税单价、不含税单价、税率、含税金额、库位、批次编码、状态。
- 当前仅有一条期初入库明细 `IN-2026-0001`；入库单号可进入来源详情。

## Forge 处理结论与边界

- 使用 `ForgePageHeader`，字段、顺序、筛选、20 条分页和来源跳转对齐当前页面。
- 增加逐行及当前页勾选；未勾选时导出全部筛选结果，勾选后只导出所选明细并显示数量。
- 其他入库的“供应商/对方”读取客户或供应商真实字段；缺少税率、库位等来源字段时显示 `—`，不推断数值。
- RISEMAP 同材料跨五类来源、勾选导出文件内容仍待复核，页面保持 `review_required`。
