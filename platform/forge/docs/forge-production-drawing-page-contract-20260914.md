# 生产 / 图纸管理页面合同与验收记录

日期：2026-09-14

## 范围与结论

本轮覆盖图纸总览、图号档案、图纸评审、图纸发布、图纸变更、图纸发放、关联查询和客户图纸八个核心入口。Forge 已形成可办理的核心业务链，并完成内置浏览器、API 与同一 SQLite 停服重启回读。RISEMAP 当前缺少可办理图纸数据，因此结论是“Forge 核心执行闭环已证明，RISEMAP 同材料成功链待复核”，不描述为全量页面等价。

`金一涛` 与 Forge 的 `Dev Admin` 按同一业务用户对照，名称差异不计为产品缺口。

## 本轮可见操作证据

- RISEMAP 实时打开并核对：`/drawing/overview`、`/drawing/archives`、`/drawing/reviews`、`/drawing/releases`、`/drawing/changes`、`/drawing/distribution`、`/drawing/association`、`/drawing/customer`、`/drawing/customer/create`。
- Forge 实时打开并核对：`page_drawing_archive`、`page_drawing_review`、`page_drawing_release`、`page_drawing_change`、`page_drawing_distribution`、`page_drawing_query`、`page_customer_drawings`。
- 内置浏览器在关联查询中将项目引用从冻结 V1.0 的“待版本复核”办理为采纳当前 V1.1；旧引用保留为“已由新关联替代”。
- 内置浏览器新建 `CDW-FILE-BROWSER-002`，选择两份客户原图、PDF、技术要求和其他附件共 5 个真实文件，提交后列表及文件清单均可回读。
- 内置浏览器新建 `CDW-DRAFT-20260914`，先保存为草稿并从列表“继续填写”，补充合同号和订单号后提交为有效；完整停服重启后页面仍可回读。
- RISEMAP 图纸发布列表实时确认“建议生效日期”列；Forge 新建发布单使用标准日期控件填写该日期，并在发布列表回读。API 生命周期验收保存 `2026-09-16` 后完成审核与发布。
- Forge 发布草稿 `DP-1789325861324` 已在内置浏览器通过标准二次确认取消，确认框显示影响并强制填写取消原因；页面回读为“已取消”，完整停服重启后保留原因。API 另验证待审核发布单取消后版本恢复为“已评审”，取消单不能再次正式发布。
- 内置浏览器完成单人发放确认和多人 2/2 确认回执，父单显示“全部已确认、已回执、已满足确认要求”。

## 工程与持久化证据

以下验收均使用 `http://localhost:4356` 和同一 `.objectstack/data/objectstack.db`：

- 图纸生命周期：正常路径和阻断用例通过，重启后 V1.0/V1.1、发布、变更、发放、客户图纸和操作日志可回读。
- 业务关联：物料、BOM、项目、采购单、组装单的冻结版本和替代链通过，重启后可回读。
- 多接收人发放：全部确认与任一确认门槛、逐人回执和父子状态一致，重启后可回读。
- 客户图纸附件：真实字节上传、格式约束、登录下载、内置浏览器提交与 5 个文件清单通过，重启后可回读。
- `pnpm typecheck`、`pnpm validate`、`pnpm build` 通过。构建保留项目既有 react-source `className` 作者期警告，本轮没有新增失败门禁。
