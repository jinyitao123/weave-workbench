## 空表单首屏结构目标

以下顺序必须与 RISEMAP 当前页一致。模型发现实时页面与本节冲突时，必须先更新“RISEMAP 当前事实”，记录冲突，再按实时页面实现。

1. 产品外壳之后出现页面级页签/导航和业务面包屑；外壳可以裁剪，业务内容不能裁剪。
2. 返回动作、`新建销售订单` 标题、`直接新建` 状态和 `草稿` 状态位于标题区。
3. 第一张卡片为 `订单来源`，包含并排的 `直接新建` 和 `关联合同` 两张选择卡；选中态有明确蓝色边框和浅色背景。
4. 第二张卡片为 `订单基本信息`，首屏两列排列：订单名称/客户单号、客户/客户联系人、联系电话/计划交货日期、收货地址、备注。
5. 物料、结算、附件或其他折叠区按照 RISEMAP 当前 DOM 顺序继续向下，禁止为了让首屏更短而提前、合并或隐藏。
6. 页面底部固定操作栏左侧显示订单金额，右侧依次显示预览、保存、提交；固定栏不得遮挡最后一行表单或明细。
