- pageId：`page_sales_order_workspace`

## Forge 当前能力

- 页面按绿色头图、订单/明细页签、主动作、两行筛选、排序、宽表和分页组织，当前可读取 11 张订单、11 条明细及页面金额。
- 搜索、范围、状态、开票、收款、发货单、发货、负责人、客户联系人和计划交货日期筛选均作用于真实列表。
- 支持当前结果 CSV、导入模板下载、标准订单台账入口、行选择和同客户合并开票前置校验。
- 合并开票把所选订单带到销售开票申请页；当前尚未证明下游真正合并生成一张发票。
- 草稿订单可提交审批，待审批订单可同意，执行中或部分发货订单可创建发货单；发货表单校验单号、日期、收货人、地址和正数数量。
- 订单明细页签展示物料、数量、发货和开票数量、价格、税率、折扣、金额、交期和来源合同。
- 1280×900 与 760×900 实际截图复查未发现可见工具栏、筛选和表格控件相互覆盖；全组几何扫描为零相交。

## 明确差异与产品决策

- 合并开票目前只完成同客户校验和下游承接，没有证明 RISEMAP 对应的合并结果、价税口径和发票来源关系。
- 导入采用标准订单台账承接，尚未复刻 RISEMAP 批量任务进度和错误回执。
- Forge 的提交审批、审批通过和发货建单使用两步确认，属于产品安全决策。
- `Dev Admin` 与 RISEMAP `金一涛` 按同一业务用户对照。
- Console 外壳只能按固定裁剪坐标排除，业务内容必须纳入像素重算。
