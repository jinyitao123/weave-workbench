# 框架销售合同逐页交付合同

## 页面身份

- pageId：`page_sales_contract_workspace`
- RISEMAP：`https://risemap.cn/sales/contracts`
- Forge：`http://localhost:3000/_console/apps/forge/page/page_sales_contract_workspace`
- 岗位：销售负责人、合同经办人、审批人
- 核心任务：维护客户合同，推进审批和执行，跟踪下单、开票、发货、回款
- 主单据：框架销售合同
- 来源：客户、联系人、项目、已审批且客户接受的销售报价
- 下一岗位：销售订单经办人；执行阶段继续承接发货、开票和回款
- 主原型：任务工作台型；参考 `project-task-workspace.page.ts`
- 当前状态：实现完成；逐页状态仍为 `review_required`，原因是像素差图未形成可提交文件，且 RISEMAP 当前特价单/询价单均为 0 条，无法完成同数据导入复核。

## Forge 当前能力

- 页面按业务头图、动作、筛选、排序、宽表、分页排列，并读取持久合同、订单、报价、客户、联系人、用户、项目和合同类型。
- 搜索及九类筛选均作用于实际列表；支持全选、行选择、紧凑密度、列表设置、刷新、当前页/全部筛选/执行明细/自定义 CSV 导出以及批量任务入口。
- 新建合同使用专用业务页而非通用对象表单，字段顺序、客户联动、报价导入、粘贴/CSV 导入、物料组合导入、订货约束、费用、收入规则、条款、附件上传、预览、保存和提交均为真实交互。
- 草稿合同可提交审批，待审批合同可同意，执行中合同可创建销售订单；动作使用标准两步确认弹窗并在页面回读结果。
- 创建订单校验订单编号、名称、计划交货日期和付款条件，写入后重新加载合同与关联订单。
- 1280×900 与 760×900 控件几何复扫未发现页面根横向溢出、控件相交、文字裁切、非表格控件越界或过小点击目标。

## 明确差异与产品决策

- RISEMAP 的特价单和询价单当前均无可办理数据，Forge 也没有可追溯的销售特价/询价来源对象，因此不显示假入口，保留明确业务说明；该项待有同材料后定向补证。
- Forge 的 Excel 导入当前接受 CSV/TSV/TXT（可由 Excel 另存），尚未直接解析 `.xlsx`；列表批量导入沿用平台标准导入任务。
- Forge 的提交、审批和创建订单保留两步确认及业务影响说明，这是产品安全决策。
- `Dev Admin` 与 RISEMAP `金一涛` 按同一业务用户对照，不作为功能或视觉缺口。
- Console 外壳可在逐页像素证据中固定裁剪，业务内容区不得因平台差异豁免。
