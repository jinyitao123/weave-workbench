# Forge 委外管理上手指南页面合同（2026-09-16）

## 页面职责与原型

- RISEMAP：`https://risemap.cn/subcontract/guide`；Forge：`page_subcontract_guide`。
- 岗位：委外业务员、仓库人员、质检/收货、财务人员。
- 主原型：配置型；复用 `ForgePageHeader`，首屏依次为标题与委外看板入口、角色与进度、六阶段、八类目录、当前指南和真实业务入口。
- 指南只解释委外办理顺序和阻断，不在本页代替订单、发料、回厂、退料、异常、对账或应付动作。

## RISEMAP 当前实时事实

- 标题“委外管理上手指南”，说明按实际任务完成订单、发料、回厂和对账。
- 四角色文章数依次为委外业务员 13、仓库人员 7、质检/收货 5、财务人员 6；角色切换改变说明、关注阶段、目录数量和文章。
- 六阶段为准备供应商、创建委外订单、委外发料、回厂验收、异常处理、对账结算；不属于当前角色的阶段不可选择。
- 八类目录为快速开始、订单管理、发料管理、回厂与质检、退料与赔偿、对账结算、库存与报表、常见问题。
- 当前实时核对了准备供应商、供料方式、订单创建/审核、发料、回厂、退料/赔偿、对账、库存/报表和反审核问题；代表文章同时提供查看入口和新建/录入入口。

## Forge 处理结论

- 从通用路由文件拆出独立 `subcontract-guide.page.ts`，同时移除已无导出的旧通用页面配置和生成器。
- 按角色精确提供 13/7/5/6 篇指南；不适用阶段和数量为零的目录显示为说明状态，不作为可点击按钮。
- 文章主动作均进入现有委外业务页面；RISEMAP 已观察的查看/新建双入口保留为两个真实导航动作，新建入口使用 Forge 决策的 `?new=1` 上下文契约直接打开目标页新建表单（委外订单、发料单、回厂记录、退料单），对账因需先选来源只保留进入对账池一个入口，并在正文说明先选来源。
- 学习状态是当前浏览器偏好，可标记、取消和刷新回读，不冒充服务器业务状态。

## 证据边界与验收材料

- 学习状态是否跨设备同步、角色是否与账号权限联动未验证，保持 `review_required`。
- 搜索口径：RISEMAP 在选中目录下搜索会跨当前角色的全部指南命中正文，Forge 采用同一口径（标题、摘要、场景、前置、步骤、完成标志、阻塞说明全部参与匹配）；命中集合受指南正文文案影响，需按关键词继续抽查。
- `?new=1` 是 Forge 上下文决策，用于从指南直接进入目标页新建表单；目标页仍保留自身主按钮，未识别该参数时行为不变。
- 静态职责与入口：`apps/forge-objectstack/tests/subcontract-guide-page.static.mjs`。
- 页面交互与深链证据：`apps/forge-objectstack/tests/page-acceptance/subcontract-guide-browser-readback-20260916.json`；最终构建的看板按钮、窄屏与控制台扫描待复核。
