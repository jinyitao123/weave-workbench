# Forge 供应链 · 到货检验页面合同（2026-09-17）

（rm-005 至 rm-009）与 `docs/risemap-page-contracts.json`。

## 范围与结果

| 页面 | RISEMAP 说明 | 本批结果 |
| --- | --- | --- |
| 到货通知 | 采购订单审核后进入目标仓库待到货队列 | 品牌标识区 + 动作行（刷新 / 登记所选到货），16 行列表 |
| 到货登记 | 登记到货物料，进入待检或免检流程 | 品牌标识区 + 动作行（导出 / 导入导出任务 / 刷新 / 新建到货登记）+ 下一步操作 待检验库存 |
| 待检验库存 | 每个物料独立一条待检记录，关联来料检验流程 | 品牌标识区 + 下一步 检验单 |
| 检验单 | 每条检验单对应一种物料的来料检验 | 品牌标识区 + 下一步 采购入库 |
| 检验规则 | 管理检验项目模板与检验方案配置 | 品牌标识区；页面保留检验项目库 / 检验方案两个真实页签 |
