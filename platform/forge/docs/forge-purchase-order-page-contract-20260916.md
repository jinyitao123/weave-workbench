# Forge 采购订单逐页交付合同（2026-09-16）

## 页面职责与原型

- pageId：`page_purchase_order_workspace`；RISEMAP：`https://risemap.cn/purchase/orders`；Forge：`/_console/apps/forge/page/page_purchase_order_workspace`。
- 岗位：采购员与订单审批人；核心任务：核对询价中选结果、提交并审核采购订单，再交给到货通知；主单据为采购订单及明细，来源为询价、采购申请或缺料分析。
- 主原型：`task_workspace`，参考 `project-task-workspace.page.ts`。首屏为标题动作、下一步到货通知、列表/明细视图、局部筛选和订单长表；详情页呈现状态、数量、金额、审批记录和到货通知。
- 主动作：询价转单后自动提交审核；订单详情的“审核订单”；审核后“到货登记”。列表标题区的下一步按钮进入真实的到货通知队列。

## 实时事实与处理结论

- RISEMAP 当前采购订单提供订单列表/物料明细、搜索和状态等筛选、新建、导入/导出、付款、发票与下一步“到货通知”。
- Forge 询价转单保存中选供应商、目标仓库、交期、付款条件、来源申请行、金额和数量，并调用订单提交动作重算只读汇总。
- 只有已启用且已审批供应商可进入询价候选并提交订单；审核意见为空会阻断。
- 审核通过生成订单级到货通知，页面回读“已审核”、1 项物料、总数量 1、到货通知编号及下一步入口。
