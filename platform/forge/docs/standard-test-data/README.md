# Forge 标准测试数据

这里保存用于 RISEMAP 复刻、Forge 实现和后续对比验收的可重复数据集。

## 当前版本

- `risemap-oem-v0.1-research-draft.json`：2026-09-09 建立的 OEM 贯联测试草案。
- 数据性质：结构与金额关系按真实业务方式设计，企业、联系人和联系方式为测试数据。
- 当前用途：在 RISEMAP 页面从初始化开始走通客户、销售、采购、库存、生产、项目、质检、发货、开票和回款关系。
- 每条实际写入结果记录在 `risemap-oem-v0.1-run-ledger.jsonl`，其中包含页面、系统编号、上游关系、状态与证据编号。

## 刷新规则

实际业务调研完成后新增版本，不直接改写本版。新版本应注明来源材料、确认人、确认日期、字段变化、流程变化与仍未确认事项。真实敏感信息在进入仓库前必须替换为稳定的测试值，但数量关系、金额计算、状态流转和异常分支应保持业务等价。

每次完整回归使用独立的 `runId`。页面不支持某项关联时，在运行台账中记录断点，不用同名文本冒充系统关联。
