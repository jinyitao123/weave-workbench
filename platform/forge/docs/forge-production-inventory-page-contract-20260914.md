# 生产入库与生产出库页面合同（2026-09-14）

## RISEMAP 当前事实

- 生产入库：`https://risemap.cn/inventory/inbound/production`。页面标题“生产入库”，说明“管理所有入库单据”；没有手工新建按钮，提供打印条码、导出、刷新、状态和来源筛选。列为入库单号、类型、来源、入库类型、批次号、供应商/客户、仓库、入库日期、含税金额、状态、创建人、操作。当前租户列表为 0 条。
- 生产出库：`https://risemap.cn/inventory/outbound/production`。页面标题“生产出库”，说明“管理所有出库单和待出库发货单”；提供“下一步操作 生产入库”、打印条码、导出、刷新、出库类型和状态筛选。列为出库单号、关联单号、销售单号、客户单号、往来单位、物料明细、仓库、出库日期、状态、物流信息、收入确认、操作员、操作。当前租户列表为 0 条。
- 当前 RISEMAP 生产出库类型为“组装出库、委外出库”。生产入库由生产业务产生，库存台账不提供独立手工新建。
- 2026-09-15 实时展开状态筛选，当前选项为“待出库、已出库、已签收”；Forge 页面按这三个对外状态归一组装领/补料与委外发料的内部状态。

## Forge 当前实现

- `page_production_inbound_entry` 使用 `forge_production_inbound` 作为主台账，列顺序与 RISEMAP 当前生产入库页一致。成品、合格/不合格数量和库存变化作为业务列的补充信息展示；详情回读对应生产入库库存流水，“来源组装单”进入实际组装单。
- `page_production_outbounds` 汇总组装领料/补料和已生成出库结果的委外发料，列顺序与 RISEMAP 当前生产出库页一致。生产退料不计入出库，委外草稿、待审和驳回申请不冒充已形成的委外出库单。
- 两页均提供搜索、业务筛选、20 条分页、单据选择、条码预览、CSV 导出、刷新、详情和来源单跳转。页面使用 ObjectStack Console 标准外壳和共享 Forge 控件。
- 销售单号、客户单号、物流信息和收入确认仅在来源业务存在对应事实时展示；当前本地生产单据没有这些来源数据，页面显示“—”，不自行制造关系。
