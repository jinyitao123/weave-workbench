# Forge 集成调试、交付包与客户验收切片

更新于 2026-09-10。本切片承接已完工组装单和进行中项目，把一次柜机的集成调试、资料交付、客户验收、整改复验与项目完工连成可追溯业务链。

## 已实现行为

- 集成调试必须引用已有合格产出的已完工组装单，并逐项保存检查类别、标准、实测结果和证据引用。
- 调试结果存在未通过项时保持未通过状态，不能建立交付包；复测覆盖全部检查项且全部通过后才可进入交付准备。
- 交付包逐项保存资料类型、版本、必交标记和证据引用。必交资料缺失时提交被阻断，资料齐全后进入待客户验收。
- 客户验收逐项保存标准、结果、现场记录和证据引用。未通过项提交后自动生成可追溯整改项。
- 整改必须登记措施、关闭证据和复核人；整改关闭后仍需对原验收项登记复验。全部验收项通过且没有未关闭整改时，才可登记客户确认文件和意见。
- 客户确认前要求项目的所有活动计划已达 `100%`；未完成时明确阻断。通过后把验收单推进为已通过、交付包推进为客户已接收，并把项目进度和状态写为 `100% / 已完工`；实际结束日期取验收业务日期，不受服务器时区影响。
