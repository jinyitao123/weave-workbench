# 出库明细页面合同

日期：2026-09-15

## RISEMAP 当前事实

- 入口：供应链 → 出库管理 → 出库明细，地址 `/inventory/outbound/details`。
- 工具栏包含打印条码、导出、刷新；未选择明细时打印条码禁用。
- 筛选包含出库单号、物料、客户、物流单号、业务类型、状态和起止日期。
- 表格为 21 个业务列：序号、出库日期、出库单号、发货单号、业务类型、仓库、客户、制单人、物料编码、物料名称、型号、规格、单位、数量、含税单价、不含税单价、税率、含税金额、库位、物流单号、状态；另有行选择框，默认每页 20 条。
- 当前租户为空，空态为“暂无匹配的出库明细”。

## Forge 当前实现

- 入口：`/_console/apps/forge/page/page_outbound_lines`。
- 以只读库存流水为统一账源，汇总销售、其他、采购退货、生产、委外、报损、锁定、调拨和借出等出库明细。
- 来源有真实字段时展示发货单、客户或供应商、物流方式；当前账源没有税率、未税价、库位或物流单号时显示 `—`，不伪造数据。
- 行选择后打印条码打开真实预览，导出生成当前筛选结果 CSV；所有筛选和分页在页面即时生效。

## 本轮验收

- RISEMAP 与 Forge 在内置浏览器实时核对工具栏、筛选、列顺序、空态和分页。
- Forge 回读 15 条真实出库流水；搜索 `UI-RET-20260915-001` 后只保留采购退货出库一行，并成功打开所选物料条码预览。
- API 断言出库流水均能解析仓库、SKU、物料，覆盖销售、其他、采购退货、委外、报损、调拨和借出，且每行数量等于账面库存扣减量。
- 同一 SQLite 停服重启后再次执行 API 与浏览器回读。
