# 库存总览页面合同

日期：2026-09-15

## 入口与职责

- RISEMAP：`https://risemap.cn/inventory/overview`
- Forge 当前：`/_console/apps/forge/forge_inventory_balance`
- Forge 目标：`/_console/apps/forge/page/page_inventory_overview`
- 岗位：仓库、采购、生产和经营管理人员。
- 职责：汇总账面、可用、锁定、在途、成本、销售潜力、分类和仓库分布；从汇总进入真实库存与来源业务。

## RISEMAP 当前事实

- 标题为“库存总览”，说明为“商品库存、在途、分类汇总与仓库视图”。
- 一级视图为总览、物料库存、在途库存、分类汇总、仓库视图。
- 总览显示库存总采购成本、物料种数、预估销售总价、毛利率、SKU 总数、账面总量、在途库存、库存预警、零售价物料、各仓库成本、分类数量和库存动态；库存动态提供调拨管理、报损管理入口。
- 物料库存提供所有、我负责的、我的下属负责的范围，全文搜索、分类、品牌、重置、打印、导出；表格展开账面、可用、在途、锁定、单位、含税/不含税成本、预设售价、销售总价、毛利率和状态。
- 在途库存按已审核且尚未完成入库的采购订单汇总，显示订单数、总量、金额、物料种数；支持物料汇总/订单明细、导出、刷新和搜索。
- 分类汇总显示分类数、最高占比、最高毛利、库存总额、分类成本与销售潜力及 7 列分类明细。
- 仓库视图支持按库位/物料查询，显示 SKU 数、仓库数、总数量、库存金额及 11 列库存表。
- 当前 RISEMAP 材料：1 个成品 SKU、账面/可用均为 1、在途 5（4 种物料）、不含税成本 ¥47,787.61、含税成本 ¥54,000.00。

## Forge 实现结果与差异

- `page_inventory_overview` 已替换通用对象入口，提供总览、物料库存、在途库存、分类汇总、仓库视图五个真实数据视图。
- 页面回读 7 条真实余额、3 个仓库、7 个 SKU、账面/可用/锁定数量、移动平均含税成本、库存金额、当前售价与毛利；采购在途由已审核采购订单未入库数量实时计算。
- 物料库存的全文搜索、分类、品牌、重置、打印预览和导出可办理；在途库存的物料汇总/订单明细会切换真实聚合粒度；仓库视图的按仓库/按物料查询会切换选择器和筛选逻辑。
- 总览提供真实调拨、报损、库存流水和采购在途入口，不保留无结果按钮。
- Forge 当前库存包含后续采购、其他入库、委外和退货产生的合法变化，不能强行改造成 RISEMAP 当前租户的单 SKU 数值。
- RISEMAP 的“所有/我负责的/我的下属负责的”依赖其负责人组织范围；Forge 当前库存余额没有可证明的组织下属口径，本轮没有伪造该范围筛选，保留为待组织模型对照项。

## 实现与验收决定

- 使用 `forge_inventory_balance`、库存锁定、库存流水、采购订单及明细、物料/SKU/分类、仓库作为真实来源，不创建静态指标。
- 在途数量必须由采购订单数量减去已入库来源数量计算；缺少可证明字段时明确显示不可计算，不使用调用方传入数字。
- 预估售价和毛利只在现有物料/SKU 价格字段可证明时展示；否则显示“未定价”，不伪造 RISEMAP 数值。
- 五个视图的每个按钮、筛选、打印、导出、刷新和业务跳转均需在内置浏览器实际操作；随后运行库存与采购 API 回读、同一 SQLite 停服重启以及 `typecheck/validate/build`。
