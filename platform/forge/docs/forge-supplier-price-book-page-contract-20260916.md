# 供应商价格本页面合同（2026-09-16）

## 页面与岗位

- RISEMAP 当前入口：`/purchase/pricebook`，采购管理 / 供应商价格本。
- Forge 入口：`/_console/apps/forge/page/page_supplier_price_book`。
- 岗位：采购负责人维护供应商协议报价，采购执行人员查询已生效价格。
- 主单据：供应商价格本；明细为物料规格价格条目；状态记录与导入/导出任务单独持久化。

## RISEMAP 当前观察事实

- 列表标题说明为“管理供应商报价协议、批量导入与多级折扣，沉淀采购议价成果”。
- 首屏指标为全部价格本、生效中、草稿、本页显示；状态页签为全部、草稿、生效中、已过期、已废弃。
- 页面级动作有导出、导入/导出任务、新建价格本，并提供搜索。
- 新建弹窗包含价格本名称、供应商、币种、生效日期、失效日期、全局一级折扣、全局二级折扣和备注；名称、供应商为必填。
- 页面明确展示公式：净价 = 目录价 ×（1 - 一级折扣%）×（1 - 二级折扣%），新增物料继承全局折扣。
- 当前 RISEMAP 账号列表为空，因此价格条目编辑、启用、废弃、过期转换及 Excel 文件格式尚无同材料成功办理证据。

## Forge 页面原型与办理顺序

- 主原型：`task_workspace`；参考 `project-task-workspace.page.ts`。
- 首屏顺序：标题和页面动作 → 判断指标 → 状态页签与搜索 → 价格本列表 → 分页结果。
- 主动作：新建价格本；草稿详情的主动作是添加物料价格并启用。
- 筛选作用对象：价格本名称、编号、供应商及状态。
- 详情顺序：价格本摘要 → 净价口径 → 物料价格列表 → 状态记录。
- 结果反馈：创建、增删价格条目、启用、废弃、导入、导出均回读页面状态并展示结果。
- 下一步：生效价格本进入采购定价范围；本轮不对采购订单自动取价规则作 RISEMAP 事实声明。

## 字段、状态、动作与阻断

- 主表字段：编号、名称、供应商、币种、有效期、两级折扣、条目数、状态、备注。
- 明细字段：物料规格、物料编码/名称/型号/规格/单位快照、目录价、两级折扣、协议净价、最小起订量、有效期、备注。
- 状态：草稿、生效中、已过期、已废弃。
- 动作：创建、搜索/按状态过滤、增删物料价、启用、废弃、导出列表/明细、向草稿价格本快速导入、查看任务记录。
- 阻断：名称与供应商必填；折扣限定 0 到 100；失效日期不得早于生效日期；重复物料、无效价格或起订量被阻断；无明细价格本不得启用；废弃原因必填；生效或废弃后明细只读。
- 破坏性动作：删除价格条目、废弃价格本使用标准二次确认并说明不可恢复影响。

## 事实、Forge 决策与未决证据

- RISEMAP 已观察事实：列表结构、新建字段、两级折扣公式、必填阻断和空列表表现。
- Forge 已有能力：对象 CRUD、自定义 Action、持久 SQLite、标准共享控件与登录会话。
- Forge 产品决策：在未验证 Excel 格式前提供可执行的逗号/制表符粘贴导入，不展示假文件上传；导出为 CSV，并将每次导入/导出结果持久化为任务记录。
- 尚待复核：RISEMAP 物料价格详情字段、同供应商有效期重叠规则、自动过期时点、Excel 模板及失败行下载、已生效价格如何被采购单自动采用。
