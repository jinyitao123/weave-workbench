# 采购入库页面合同

日期：2026-09-16

## 页面职责与原型

- RISEMAP：`https://risemap.cn/inventory/inbound/purchase`、`/inventory/inbound/new`；Forge：`page_purchase_inbound_workspace`。
- 岗位：仓库管理员与入库审批人；主单据：采购入库单及明细；主原型：任务执行型，参考 `task_workspace` 与 `ForgePageHeader`。
- 首屏顺序：页头与新建动作 → 搜索筛选 → 入库单列表 → 分页；详情按状态提供提交审批、审批通过、执行入库。
- 结果：正式库存余额、库存流水和采购订单入库进度。

## RISEMAP 当前事实

- 列表含新建、打印条码、导出、刷新、搜索、状态和来源筛选；列为入库单号、类型、来源、入库类型、批次、对方、仓库、日期、含税金额、状态、创建人、操作。
- 新建采购入库要求供应商和采购订单，物料行由订单带出；支持保存草稿和提交审批，状态为草稿、待审批、已审批、已入库。

## Forge 实现与产品决定

- Forge 只允许检验完成且有合格剩余数量的物料入库；支持多物料草稿、审批、正式落账和超检验合格剩余量阻断。
- 执行入库不可逆，必须使用标准二次确认并说明将增加库存；这是 Forge 产品安全决定。
- 登记采购发票属于入库后的财务承接入口，不计入本轮财务完成范围。

## 验收材料

- 验证草稿 → 待审批 → 已审批 → 已入库，库存余额/流水、重复入库阻断、同一 SQLite 重启回读和窄屏布局。
