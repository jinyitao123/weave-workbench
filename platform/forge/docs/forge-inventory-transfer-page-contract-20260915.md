# 调拨与借出页面合同

日期：2026-09-15

## 入口与职责

- RISEMAP：`https://risemap.cn/inventory/transfer`
- Forge：`/_console/apps/forge/page/page_inventory_transfer`
- 岗位：仓库经办人、库存审核人和借用责任人。
- 职责：跨仓调拨、借出、审核执行、归还与两端库存流水追溯。

## RISEMAP 当前事实

- 标题说明为“跨仓库调拨、借出归还与外协领用单据管理”。
- 有调拨单列表、调拨明细列表双视图；工具栏有新建单据、导出、刷新。
- 单据列表列为单号、业务类型、发出方、接收方、原因、物料数量、金额、状态、关联、日期/申请人、操作。
- 明细列表有两个搜索框、类型和状态筛选，列为调拨单号、单据日期、类型、物料编码、物料名称、型号、数量、发货仓库、调入仓库、含税金额、状态、制单人。
- 新建页可选择普通调拨、借出管理、变价调拨；普通调拨包含跨仓/库内模式、发货/调入仓库、原因、经办人、预计到货、承运商、物流单号和多条物料；借出联动为借出/归还方向、发货仓库、接收单位、收货地址、借用人、预计归还、用途和物料明细。
- 当前租户无单据，提交、审核、执行、归还和变价结果待同材料复核。

## Forge 实现决定

- 使用既有 `forge_inventory_operation` 的调拨/借出状态机，草稿提交后不改库存，审核执行时写双端调拨流水或借出流水，借出归还时回到原仓库并写归还流水。
- 专页对齐双视图、列表字段、搜索筛选、新建业务类型联动和二次确认；当前一张单据对应一个仓库 SKU。
- 变价调拨涉及目标仓成本重算，RISEMAP 当前无单据结果可核对，页面明确说明暂不提供未验证入口。
- 多物料头/明细、库内移位、承运信息和外协单位主数据仍为待 RISEMAP 同材料复核，不写成已完成。

## 验收材料

- 两侧内置浏览器首屏、双视图、新建类型联动、草稿、提交审核、审核执行、借出归还和停服重启页面回读。
- Forge API 对单据、两端余额及调拨/借出/归还流水的同一 SQLite 回读。
- `pnpm typecheck`、`pnpm validate`、`pnpm build`、页面控件可用性检查。
