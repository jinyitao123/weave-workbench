# 检验规则页面合同

日期：2026-09-15

## 实时 RISEMAP 事实

- 入口：`https://risemap.cn/inventory/inspection-rules`。
- 页面包含“检验项目库”和“检验方案”两个页签；当前租户两者均为空。
- 检验项目库提供新建、批量启用、批量停用、导入、导出、刷新、全文搜索、分类/判定类型/检验类型/状态筛选和 10 条分页。
- 检验项目列为项目编码、项目名称、项目分类、判定类型、适用检验类型、单位、是否必检、影响整批结论、是否启用、更新时间、操作。
- 新建检验项目分为基本信息、判定规则、录入控制、质量属性；判定类型包含结果型、数值型、选项型、文本型、附件型。
- 检验方案提供新建、批量启用、批量停用、复制方案、导入、导出、刷新、全文搜索、检验类型/检验方式/状态筛选和 10 条分页。
- 检验方案列为方案编码、方案名称、检验类型、默认检验方式、检验项目数、启用状态、更新时间、操作。
- 新建方案包含来料/外协/成品检验，全检/抽检/免检，指定物料/物料分类/指定供应商，以及从项目库添加检验项目。

## Forge 实现与产品决定

- Forge 入口：`page_inspection_rules`，使用 ObjectStack Console 标准页面载体。
- 新增检验项目、检验方案和方案项目关系三个持久对象；列表、筛选、新建、编辑、复制、CSV 文本导入、CSV 导出、批量启停均有真实结果。
- 批量停用使用二次确认，说明新业务匹配影响以及历史记录不受影响；这是 Forge 的业务安全决定。
- RISEMAP 当前租户无可办理数据，因此 Forge 的可写结果属于已验证本地实现，仍待 RISEMAP 同材料复核。

## 本轮验收材料

- 浏览器数据：`IQI-FORGE-20260915-001`、`IQP-FORGE-20260915-001`。
- 正常路径：项目新建并启用 → 方案选择项目并启用 → 方案停用确认 → 重新启用。
- 异常与阻断：项目名称、适用检验类型、方案名称和适用范围均有提交阻断；停用必须二次确认。
- API：`pnpm acceptance:inspection-rules-readback`。
- 持久化：同一 `supply-chain-pages.sqlite` 完整停服重启后 API 和页面回读。
