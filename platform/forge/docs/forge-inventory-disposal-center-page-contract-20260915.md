# 库存处置执行中心页面合同

日期：2026-09-15

## 入口与职责

- RISEMAP：`https://risemap.cn/inventory/disposition-execution`
- Forge：`/_console/apps/forge/page/page_inventory_disposal_center`
- 岗位：质量、仓库、采购与异常处置执行人员。
- 职责：统一跟踪不合格处置执行，按退回、复检、报废与让步入库推进闭环。

## RISEMAP 当前事实

- 首屏指标为执行单总数、待执行、执行中、异常待处理。
- 状态页签为全部、待执行、执行中、已完成、执行异常，并显示各自数量。
- 工具栏包含刷新、全文搜索、处置类型、退回类型；未选退回处置时退回类型不可用。
- 表格列为执行单号、处置类型、来源业务、物料、执行数量、当前阶段、更新时间、操作，分页每页 20 条。
- 当前租户无处置执行单，行操作与异常恢复细节保持待同材料复核。

## Forge 实现决定

- 以已有委外 NCR、采购退换货和库存报损单作为真实处置来源，按来源状态派生统一执行阶段，不创建脱离来源的重复单据。
- 委外 NCR 进入委外不合格办理页，采购退换货进入退换货工作页，报损进入报损办理页；统一页只承担跟踪、筛选和来源回溯。
- 状态页签、搜索、处置类型和退回类型均改变真实结果集；未选退回处置时退回类型禁用。
- RISEMAP 当前无数据，因此 Forge 的有数据行办理结果保持待 RISEMAP 同材料复核。

## 验收材料

- 两侧内置浏览器首屏、状态页签、筛选、刷新和行办理入口。
- Forge API 对来源、数量、状态与来源关系的重启回读。
- `pnpm typecheck`、`pnpm validate`、`pnpm build`、页面控件可用性检查。
