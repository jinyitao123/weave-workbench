# 供应链库存日常作业页面合同（2026-09-14）

## 范围和验收口径

本合同覆盖库存锁定、库存盘点、调拨与借出、库存预警、报损单和 SN 码管理。RISEMAP 当前线上页面是入口、字段、列、状态和交互的首要证据；Forge 继续使用 ObjectStack Console 页面语言。`金一涛` 与 `Dev Admin` 作为同一业务用户对照。

“通过”要求同一业务材料在两侧完成页面办理，并由 Forge API、同一 SQLite 停服重启回读补充证明。RISEMAP 当前没有可办理数据或页面自身阻断时，只记录已观察事实和 Forge 已运行结果，不写成同材料对照通过。

## Forge 产品决策

- 删除、作废、释放、撤销等会改变业务结果的动作统一使用标准二次确认弹窗。
- 弹窗只使用业务语言。确认区显示“单据、物料、数量、仓库、业务影响”，不显示“对象、实体、记录 ID”等技术术语。
- 新增表单保存按钮按业务结果命名为“保存草稿”或“保存预警参数”；SN 页面只保留 RISEMAP 已观察的记录和验证动作，不提供本地手工登记假入口。
- 暂未实现的变价调拨、库内移位、交期预警和完整 SN 生命周期不做假按钮，保留为明确缺口。
