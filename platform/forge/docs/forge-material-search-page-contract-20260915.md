# 综合物料搜索页面合同（2026-09-15）

## 页面与岗位

- RISEMAP 入口：`/base/material-search`
- Forge 入口：`/_console/apps/forge/page/page_material_search`
- 页面职责：单件查看物料完整档案与历史价格；批量识别物料清单并测算库存、价格、供货能力和缺口。
- 主要岗位：销售报价、采购、计划和仓库人员。

## RISEMAP 当前已观察事实

- 页面包含“单件查询”和“批量清单分析”两个模式。
- 单件查询可按编码、名称、型号、品牌、供应商、物料组合、SN 码和批次号搜索，并按全部结果、物料、型号、品牌、供应商、批次码和追溯码分类。
- 物料详情展示型号、品牌、规格、单位、负责人、含税/不含税销售价、含税/不含税成本价，以及采购记录和销售记录。
- 批量清单接受编码、型号或名称，后跟数量与单位；识别制表符、逗号、顿号和多个空格，并自动跳过表头。
- 分析结果显示行数、带数量行、识别/未匹配数量、预计金额、现货满足/缺口、交期依据和风险；表格含采购价、销售价、库存、供货能力、预计交期和金额小计。
- 提供修改清单、清空、示例、识别分析、手动匹配、选择客户、排序、复制文本、导出 Excel 和导出 PDF。

## Forge 当前实现

- 单件查询接入真实物料、SKU、库存余额、仓库、供应商、采购明细和销售明细；可按编码、名称、型号、品牌和采购供应商搜索。
- 详情回读型号/规格、品牌、当前/可用库存、仓库、四种含税/不含税价格，以及可切换的采购/销售记录。
- 批量清单支持粘贴 Excel/WPS 或 CSV 文本、自动跳过表头、示例、清空、识别分析、复制文本和 CSV 导出。
- 供货分析使用当前可用库存和 SKU 成本价/最近采购价，明确区分现货满足、部分现货、需采购和未匹配物料，不把确定性计算冒充 AI 结论。

## 明确差异与待办

- RISEMAP 的物料组合、SN、批次码和追溯码搜索尚未纳入 Forge 单件统一索引。
- 客户历史成交价、人工匹配、交期历史统计、供货排序、Excel/PDF 文件导出尚未实现；Forge 当前不显示这些假入口。
- Forge 当前“导入 Excel / CSV”展示复制粘贴说明，不上传文件；实际解析发生在清单输入框。
