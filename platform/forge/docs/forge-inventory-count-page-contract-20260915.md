# 库存盘点页面合同

日期：2026-09-15

## 入口与职责

- RISEMAP：`https://risemap.cn/inventory/check`
- Forge：`/_console/apps/forge/page/page_inventory_count`
- 岗位：仓库盘点人员、库存主管与财务复核人员。
- 职责：制定盘点计划、录入实盘数量、形成盘盈盘亏结果并回写库存流水。

## RISEMAP 当前事实

- 标题为“库存盘点”，说明为“制定盘点计划、执行盘点与盘亏盘盈处理”。
- 工具栏包含新建盘点、导出、刷新；筛选包含全文搜索、状态、类型、仓库。
- 表格列为盘点编号、盘点名称、盘点仓库、盘点类型、计划日期、实际日期、盘点进度、差异项、盘差、状态、锁账、操作人、创建时间、操作，分页每页 20 条。
- 当前租户无盘点记录；新建后的多物料进度与操作细节保持待同材料复核。

## Forge 实现决定

- 继续使用 `forge_inventory_operation(operation_type=count)` 和既有完成盘点 Action，避免绕开库存余额与流水。
- Forge 当前一张盘点单对应一个仓库 SKU；列表按真实单据显示计划/实际日期、完成进度、差异项、盘差、锁账和操作人。
- 新建先保存盘点草稿；“完成盘点”二次确认后才按实盘数量调整余额，只有账实差异时生成盘盈/盘亏流水。
- 本轮用账实一致材料验证闭环，不改变当前库存数量；多物料盘点头/明细模型仍为待 RISEMAP 同材料复核。

## 验收材料

- 两侧内置浏览器首屏、筛选、新建表单、二次确认、完成状态与重启回读。
- Forge API 对盘点单、余额及差异流水的同一 SQLite 回读。
- `pnpm typecheck`、`pnpm validate`、`pnpm build`、页面控件可用性检查。
