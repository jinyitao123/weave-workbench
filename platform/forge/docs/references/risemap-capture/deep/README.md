# RISEMAP 深度走查证据

新产生的深度操作证据按 `业务大类/功能域/功能编号` 分目录保存。每次用户可见动作仍同时写入上级 `steps.jsonl`，业务含义写入 `deep-records.jsonl`，纵向工作簿由索引脚本自动汇总。

单条深度记录包含以下字段：

- `recordId`：稳定的纵向记录编号。
- `featureId`：181 个主导航入口中的功能编号。
- `stage`：如空表单、校验、已填写、提交结果、详情、状态转换、下游核对、异常或权限。
- `action`：本次实际执行的用户动作。
- `result`：页面实际反馈，不根据预期补写。
- `businessImpact`：数据、状态、数量、金额或上下游单据的可观察变化；未核对时明确写待核对。
- `evidenceStep`：指向 `steps.jsonl` 中保存截图与页面文字的步骤。

测试资料统一使用“Forge测试”前缀。截图目录只用于证据归档，不在其中保存账号密码。
