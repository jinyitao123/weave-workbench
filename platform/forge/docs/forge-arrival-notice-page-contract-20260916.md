# 到货通知页面合同

日期：2026-09-16

## 页面职责与原型

- RISEMAP：`https://risemap.cn/inventory/arrival-notices`；Forge：`page_purchase_arrival_notice`。
- 岗位：采购员；主单据：到货通知；主原型：任务执行型，参考 `task_workspace` 与 `ForgePageHeader`。
- 首屏顺序：页头与办理动作 → 搜索筛选 → 待到货队列 → 分页；主动作是从一条可到货通知进入到货登记。
- 下一步：到货登记。筛选只作用于当前到货通知列表。

## RISEMAP 当前事实

- 页面列为选择、到货通知、供应商/物料、预计到货、目标仓库、来源采购订单、到货进度、采购员、操作。
- 提供搜索、预计到货日期范围、仓库、状态、逾期筛选、刷新和“合并到货登记”。当前租户列表为空，合并动作没有可办理材料。

## Forge 实现与未决项

- Forge 已有采购订单审核后生成通知、单条通知登记到货和来源回溯能力。
- 本轮只暴露已验证的单条“登记所选到货”；RISEMAP 多通知合并的兼容条件、字段和结果仍待同材料复核，不以按钮名称伪装完成。

## 验收材料

- Forge 现有材料：`PO-1789546200198-AN-001`；需验证选择、进入登记、返回列表、筛选与窄屏布局。
- API/持久化由采购到货集成链和同一 SQLite 停服重启回读证明。
