# 考勤统计逐页复刻记录

## 页面合同

- 页面：`page_attendance_statistics`
- RISEMAP：`https://risemap.cn/hr/stats-dashboard`
- Forge：`http://localhost:3001/_console/apps/forge/page/page_attendance_statistics`
- 岗位：考勤管理员、人力资源负责人
- 主原型：分析型
- 页面职责：按日期范围查看考勤指标、趋势、状态分布、部门排名、迟到分布及部门汇总。

## 2026-09-21 RISEMAP 当前事实

- 当前页面没有旧合同中的“考勤分析 / 请假出差 / 在岗情况”页签，首屏直接呈现考勤统计分析；本轮以当前线上页面为准。
- 标题区为深蓝紫色数据图表主题，标题“考勤统计”，说明为“考勤数据可视化分析、请假出差趋势、部门维度图表”。
- 标题下方提供查看考勤详情、开始日期、结束日期和本月按钮。
- 六项指标依次为总出勤率、总记录数、迟到次数、早退次数、旷工次数、平均工时。
- 分析区包含每日考勤趋势、考勤状态分布、部门出勤率排名、迟到时长分布和部门考勤雷达图；底部部门表格列为部门、正常、迟到、早退、旷工、出勤率、平均工时。
- 当前线上日期范围内为零数据；迟到分布仍显示四个时长区间和“30分钟以上迟到需重点关注”提示。

## Forge 本轮实现与验证

- 页面脱离通用行政记录模板，改为独立分析页；数据从 `attendance_management` 已持久化记录按日期范围实时聚合，不另造统计台账。
- 实现与 RISEMAP 当前页面一致的日期控制、六项指标、五个分析区块和部门汇总表；无数据时保留与线上同义的明确空态。
- “查看考勤详情”真实进入考勤管理页；本月和刷新均实际生效。
- 当前记录没有足够维度时，部门雷达图区明确说明数据不足，不用假图形冒充结果。
- 内置浏览器已同时打开 RISEMAP 与 Forge 当前页面复核首屏结构；Forge 的本月、刷新和查看考勤详情均完成页面级点击，详情入口成功进入 `page_attendance_management`。
- Forge 桌面首屏中日期控件、按钮和六项指标保持独立间距，分析卡片为双列布局，未见按钮、输入框或指标卡相互覆盖。
