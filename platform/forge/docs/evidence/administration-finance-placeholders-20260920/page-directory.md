# 通讯录逐页复刻记录

## 页面合同

- 页面：`page_directory`
- RISEMAP：`https://risemap.cn/hr/contacts`
- Forge：`http://localhost:3001/_console/apps/forge/page/page_directory`
- 岗位：全体员工、人力资源管理员
- 主原型：配置型与组织视图组合
- 页面职责：按组织、姓名、岗位和状态检索员工联系方式，并查看组织架构。
- 主动作：导出 Excel；视图切换为通讯录与组织架构。
- 来源关系：直接读取 `forge_employee_record`，不再使用通用行政记录模拟员工。

## 2026-09-21 RISEMAP 当前事实

- 标题区为蓝绿渐变组织关系主题，标题“通讯录”，摘要显示在职员工数、部门数和子部门数。
- 顶部动作依次为导出 Excel、通讯录、组织架构。
- 通讯录视图左侧为组织架构树，包含全部展开、收起、全部部门和部门节点；右侧提供姓名/岗位/部门搜索、全部状态、排序与人数。
- 当前线上为空数据，显示“未找到匹配的员工”。
- 组织架构视图提供放大、缩小、重置视图和导出，画布展示部门节点，图例包含负责人和组长。

## Forge 本轮实现与验证

- 独立页面直接读取员工档案，按在职状态计算标题摘要，按部门构造组织树和组织图。
- 搜索、状态筛选、部门筛选、正倒序、全部展开和收起均在当前员工集合上真实生效。
- 导出 Excel 生成可打开的 `.xls` 文件；组织架构导出生成当前部门节点的 SVG，缩放与重置实时作用于画布。
- 员工卡片明确限制长姓名、岗位和部门为单行省略，避免挤压相邻控件。
- 本轮实时打开 RISEMAP `/hr/contacts`，分别核对通讯录与组织架构视图；随后在 Forge 逐项点击通讯录/组织架构切换、全部展开、收起、正倒序、搜索、放大、缩小、重置和两类导出。
- 长搜索词 `超长压力测试姓名ABCDEFGHIJKLMNOPQRSTUVWXYZ` 未挤压状态选择器、排序按钮或人数；当前桌面和侧栏展开宽度下未见控件重叠、文字竖排或越界。
- 组织架构缩放从 75% 到 85% 可回读并可恢复；实际下载生成 `组织架构.svg` 和 `通讯录.xls`。
- 完整停止 Forge 后使用同一 `.objectstack/forge.sqlite` 重启，页面回读仍为 0 名在职员工、1 个部门、1 个子部门，与重启前一致。
- Codex 内置浏览器控制前段连续返回连接策略错误；提交后连接恢复，并在内置浏览器重新打开 Forge 通讯录，现场回读菜单入口、标题摘要、组织树、搜索、状态、排序和空态。RISEMAP 同视口原图、Forge 原图落盘、叠图/像素差和第三档窄屏证据仍未补齐。
