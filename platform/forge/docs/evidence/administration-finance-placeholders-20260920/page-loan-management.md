# 借出管理逐页复刻记录

## 页面合同

- 页面：`page_loan_management`
- RISEMAP：`https://risemap.cn/ops/lending`
- Forge：`http://localhost:3000/_console/apps/forge/page/page_loan_management`（本轮对照端口 `3001`）
- 岗位：借用申请人、审批人、物品经办人、行政负责人
- 主原型：任务执行型
- 页面职责：登记物品借出或外部借入，承接审批、借用中跟踪、逾期提醒及归还核销。

## 2026-09-20 RISEMAP 当前事实

- 标题为“借出管理”，说明为“物品借出与外部借入（客户 / 内部员工 / 供应商 / 其他单位）的登记、审批、归还核销”。
- 状态页签依次为全部、草稿、待审批、借用中、逾期未还、已归还、已驳回，当前均为 0 条。
- 工具栏有导出、新建借用单、刷新、密度/列表设置；筛选为单号/物品/对象搜索、方向、对象。
- 列为单号/方向、物品明细、借用对象、原因、借用/预计归还、实际归还、经办人、状态、操作；页脚同时显示总数、本页借出数、本页借入数和每页条数。
- 新建借用单是标准弹窗。业务方向为借出/借入；对象类型为客户、内部员工、供应商、其他单位；对象根据类型搜索选择。
- 物品明细支持物品名称/型号、数量、单位与追加多行，单位至少包含台、套、个、件、卷。
- 借用原因提供测试使用、客户试用借出、项目现场借用、维修借用，也可输入自定义原因；选项来源提示指向“系统 → 业务设置”。
- 日期为借出日期和预计归还日期，另有备注。保存草稿、提交审批在必填材料不完整时均不可用；提示“提交后进入审批流，审批通过后借用生效”。
- 页面规则说明：借入只记数量、不计成本、不产生应付且可转借；对象类型四类统一；借给同事不产生往来挂账，物品挂个人名下并提醒逾期；借出和借入分别在归还后核销。

## 2026-09-20 Forge 实现与页面复核

- 已由通用行政占位页切换为独立任务执行页；移除了不属于 RISEMAP 当前页面的四张指标卡。
- 首屏现已覆盖 RISEMAP 的标题说明、七个状态页签、导出/新建/刷新/列表设置、搜索/方向/对象筛选、九列列表、借出借入页脚口径和借用规则说明。
- 新建弹窗现已覆盖借出/借入方向卡片、四种对象类型、对象名称、多行物品、数量和单位、快捷/自定义原因、借用与预计归还日期、备注、保存草稿和提交审批。
- 保存草稿和提交审批均写入 `forge_administration_record`，通过 `page_key=loan_management` 隔离；方向、对象、物品行及原因保存于 `details`，列表重新请求数据后回读。
- “逾期未还”不伪造数据库状态：状态为 `in_progress` 且预计归还日期早于当天时，在页面筛选、数量和状态标签中实时归为逾期。
- 640×900 窄屏实测已修正宽表空态被挤出视口的问题；状态页签可横向滚动，工具栏换行，筛选单列排列，空态主动作、页脚均可见且无按钮/输入框重叠。
- 窄屏弹窗实测确认底部“取消 / 保存草稿 / 提交审批”持续可见；点击空表单“保存草稿”会显示“请选择或填写借用对象”，没有生成测试记录。
