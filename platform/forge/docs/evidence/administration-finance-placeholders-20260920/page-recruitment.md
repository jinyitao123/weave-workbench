# 招聘管理逐页复刻记录

## 页面合同

- 页面：`page_recruitment`
- RISEMAP：`https://risemap.cn/hr/recruitment`
- Forge：`http://localhost:3000/_console/apps/forge/page/page_recruitment`
- 岗位：人事负责人、招聘专员
- 主原型：任务执行型
- 页面职责：维护岗位说明、编制、在岗人数、薪资范围、汇报对象和招聘状态。
- 主动作：新增岗位。

## 2026-09-20 实时差异

- RISEMAP 当前为绿色招聘管理横幅，说明“岗位发布、候选人漏斗、面试评估、Offer 管理”；列表顶部为新增岗位、导出、刷新、列表设置，第二行是岗位搜索和部门筛选。
- RISEMAP 当前表格包含岗位名称、部门、职级、编制/在岗、薪资范围、汇报对象、状态、更新日期和操作。
- Forge 修改前是通用行政记录页，错误展示三个人工页签和四个通用指标，列仅有岗位编号、名称、类别、部门、负责人、日期和状态，属于占位套壳。
- 本轮改为独立招聘页面，删除无当前证据的通用指标与页签，补齐当前可见列、部门筛选、可用 CSV 导出、行选择、真实新增岗位弹窗和详情弹窗。
- 当前数据仍落在现有 `forge_administration_record`，没有引入未经 RISEMAP 证明的新状态机；候选人、面试与 Offer 深层流程仍标记待取证。
