# 物料领取逐页复刻记录

## 页面合同

- 页面：`page_material_pickup`
- RISEMAP：`https://risemap.cn/ops/materials`
- Forge：`http://localhost:3001/_console/apps/forge/page/page_material_pickup`
- 岗位：行政物料管理员、物料申请人、审批人、领取经办人
- 主原型：任务执行型与配置型组合
- 页面职责：维护办公物品库和库存，提交多物品领取申请，查看待审批、待领取及已领取记录。

## 2026-09-20 RISEMAP 当前事实

- 标题说明为“办公物料申请、审批、领取与库存管理”；顶部指标依次为待审批、待领取、物品种类、库存预警和库存总值。
- 三个页签依次为领取申请、物品库和领取记录。
- 领取申请表单包含必填申请事由和可增减的多条领取物品，每行选择物品并填写数量；提交后进入审批流程。
- 物品库列为物品名称、类别、规格型号、单位、当前库存、安全库存、单价、供应商、购买渠道、库位、最近入库和操作。
- 新增物品表单包含物品名称、类别、单位、规格型号、单价、安全库存、供应商、购买渠道和库位；物品名称必填，单位默认“个”，单价默认 0，安全库存默认 5。
- 批量入库支持多条入库行，每行包含物品、数量、单价、供应商、购买渠道和备注，并可新增、复制或移除行。
- 领取记录列为申请单号、领取人、部门、物品名称、数量和领取日期，并提供导出；当前三个页签均无业务记录。

## Forge 本轮实现与页面复核

- 已替换此前只有领取申请、其余页签为说明文字的半占位实现，落地绿色主题、五项真实指标和三个可操作页签。
- 新增 `forge_administration_supply` 承接物品主数据与当前库存，新增 `forge_material_pickup_line` 承接多物品申请明细，新增 `forge_administration_supply_inbound` 承接逐次入库记录。
- 领取申请支持多行物品、数量校验、当前库存阻断，并保存主申请及明细；物品库支持真实新增和批量入库，入库会同步累加当前库存；领取记录从已领取申请及明细生成并支持真实 CSV 导出。
- 未观察到 RISEMAP 当前空数据页面上的审批和确认领取动作，因此本轮未凭工程推断增加对应按钮；审批通过、实际领用和扣减库存仍作为待取证业务缺口。
- 本轮在 Forge 实测空申请提交提示“请填写申请事由”；填写事由但未选物品时提示“请选择全部领取物品并填写大于 0 的数量”；空新增物品提示“请填写物品名称”。均未创建测试记录。
- 实测空物品库时批量入库按钮禁用、空领取记录时导出按钮禁用。开发过程中点击新增物品曾暴露未初始化明细数组的运行错误，已改为安全渲染并重新验证弹窗和阻断。
- 本轮实时回看 RISEMAP `/ops/materials` 与 Forge `page_material_pickup`；Forge 桌面首屏及 640×900 窄屏首屏/申请弹窗未见按钮、输入框或表单行重叠。
