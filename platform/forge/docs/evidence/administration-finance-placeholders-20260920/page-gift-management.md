# 礼品管理逐页复刻记录

## 页面合同

- 页面：`page_gift_management`
- RISEMAP：`https://risemap.cn/ops/gift/apply`
- Forge：`http://localhost:3000/_console/apps/forge/page/page_gift_management`（本轮独立运行端口 `3001`）
- 岗位：礼品申请人、审批人、礼品库管理员、行政负责人
- 主原型：任务执行型与库存分析型组合页
- 页面职责：处理员工礼品申请与审批，管理礼品清单、库存台账和出入库流水。

## 2026-09-20 RISEMAP 当前事实

- 标题为“礼品管理”，说明为“员工礼品申请、审批、库存与发放，覆盖商务赠礼与节日福利”。
- 四个页签依次为礼品申请、礼品清单、礼品库管理和礼品库流水，当前均为 0 条。
- 礼品申请首屏有申请总额、待处理审批、已批准金额、已发放四项指标；工具栏有新建申请、导出、刷新与列表设置；筛选为搜索、类型、状态；列为编号、申请标题、类别、申请人、赠送对象、金额、申请日期、状态、审批进度和操作。
- 礼品清单展示礼品种类、涵盖分类、平均单价；分类包含实物礼品、兑换券码、充值卡、现金红包、报销额度、生日福利、节日福利、司庆福利、入职周年、婚育福利、高温/防寒福利、体检福利、团建福利；另有推荐、排序、搜索和网格/列表视图。
- 礼品库管理有新增礼品、搜索、分类、导出、刷新和列表设置；列为编号、礼品名称、分类、规格、单价、当前库存、累计入库、累计出库、库存价值、存放位置、状态和操作。
- 礼品库流水有总流水记录、入库金额、出库金额、净变动四项指标；筛选为搜索与类型；列为流水号、类型、礼品名称、规格、数量、单价、金额、事由、关联单据、操作人和日期。
- 本轮在窄视口实时检查 RISEMAP：页签保持横向承载，表格只在卡片内部横向滚动；礼品清单的长分类列表形成独立纵向区域。

## 2026-09-20 Forge 实现与实时复核

- 已由通用行政占位页切换为独立 `gift-management.page.ts`，四个页签拥有各自的指标、工具栏、筛选、空态和表格列，不再共用申请页结构。
- 礼品申请已实现 RISEMAP 当前观察到的四项指标、搜索/类型/状态筛选、申请列、新建申请弹窗和 CSV 导出；空提交实时出现“请填写申请标题”。
- 礼品清单已实现三项指标、完整分类、推荐筛选、价格排序、搜索及网格/列表切换；价格排序控件会改变当前数据顺序，不再是占位控件。
- 礼品库管理已实现新增礼品、分类搜索、库存口径与完整列；新增礼品空提交实时出现“请填写礼品名称”。
- 礼品库流水已实现四项指标、类型筛选和 RISEMAP 当前列顺序；空数据下导出保持不可用，避免无反馈按钮。
- 两侧实时核对页面：RISEMAP `https://risemap.cn/ops/gift/apply`；Forge `http://localhost:3001/_console/apps/forge/page/page_gift_management`。本轮在 Forge 实际点击四个页签、新建申请、新增礼品、两类必填阻断、推荐/排序/视图入口，并检查桌面首屏与 `640×900` 窄屏。
- 截图复核发现并修正了指标卡 SVG 未限尺寸、图标挤占卡片的问题；修正后四项指标恢复紧凑排布，窄屏指标改单列，工具栏与筛选未相互覆盖，分类区与表格在自身容器内滚动。
