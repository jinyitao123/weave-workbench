# 固定资产逐页复刻记录

## 页面合同

- 页面：`page_fixed_assets`
- RISEMAP：`https://risemap.cn/ops/assets`
- Forge：`http://localhost:3001/_console/apps/forge/page/page_fixed_assets`
- 岗位：行政资产管理员、部门资产责任人、折旧经办人
- 主原型：任务执行型
- 页面职责：维护固定资产台账、折旧参数和月度折旧结果，为使用人变更与报废流程提供资产基线。

## 2026-09-20 RISEMAP 当前事实

- 标题说明为“资产台账、折旧核算、使用人变更、报废流程的统一管控”。

- 已让行政导航中的 `page_fixed_assets` 使用专用页面源，替换此前仍由通用行政占位模板承载的运行时页面。
- 已按 RISEMAP 当前结构落地青蓝资产主题、动作工具栏、四项筛选、13 列台账、空态和每页 20 条分页信息。
- `forge_fixed_asset` 新增品牌、规格型号、折旧方法、使用年限、残值率、供应商、存放地点、发票号和最近计提月份；必填字段与 RISEMAP 当前表单一致。

- 本轮新增本地走查资产 `审计走查-固定资产-20260920`，分类“测试设备”、使用部门“研发部”、责任人“金一涛”，原值 12,000 元；保存成功反馈、列表金额与状态回读均正确。完整停止服务并使用同一 `.objectstack/forge.sqlite` 重启后，该资产及折旧参数仍可见，持久化回读通过。
