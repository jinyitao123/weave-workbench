## 各页首屏（自上而下）

所有页面都是同一骨架：**品牌标识区（hero）→ 指标卡 → 状态页签 → 动作行 → 搜索/筛选行 →
宽表 → 分页**。hero 都含业务面包屑「组装业务管理 › 页面名」、图标徽章、标题、一句说明与右侧线稿装饰。

## 动作行与筛选行

- 动作行顺序统一为：`新建X`（主按钮，最左）→ `导出`（带下拉箭头）→ `导入/导出任务`；
  右侧为刷新等图标按钮。组装单页另有「导出」下拉展开项。
- 筛选行：一个搜索输入框（占位分别是「搜索单号/成品/BOM/来源订单...」「搜索领料单号/成品/来源单...」
  「搜索补料单号/成品/组装单...」「搜索退料单号/成品/组装单...」「搜索拆解单号/成品/BOM...」
  「搜索换件单号/成品/物料编码...」），领料单另有 `全部类型` 下拉；其余页面只有搜索框。
- 缺料待办没有动作行与筛选行，只有指标卡与内容区。

## 边界

- 抓取时该租户组装业务数据为空态，因此**有数据时的行内容、行操作与批量操作没有可观察事实**；
  拆解单与换件单的表头里也没有「操作」列（组装单有）。这两页在 Forge 侧保留办理入口属产品决策。
- 生产准备检查在 RISEMAP 侧没有对应页面（其内容对应上手指南与系统配置），Forge 该页属产品决策。
- 顶部导航、文档页签栏与左侧栏是 RISEMAP 自有外壳，Forge 使用 ObjectStack Console 外壳，
  按精修基线属于可接受差异。
