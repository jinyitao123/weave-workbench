# 图纸管理实时复刻与验收记录（2026-09-20）

## 结论

Forge 图纸管理 9 个页面已完成本轮可验证范围的页面、字段与业务链补齐：图号档案、评审、发布、
变更、发放、关联查询和客户图纸都可在 Console 中办理，新增档案字段与业务规则可持久化，发布版本链、
业务影响和文件资源树均读取真实数据。隔离 SQLite 的四条业务链、内置浏览器操作和停服重启回读通过。

双侧最终验收仍为 `review_required`。原因不是 Forge 未实现，而是 RISEMAP 当前租户的保密等级字典不可用，
导致同一组审计材料无法保存草稿，无法继续评审、发布、变更与发放的 RISEMAP 成功链。

## RISEMAP 当前事实与阻塞

在 RISEMAP 新建对照材料时填写：

- 图号：`AUDIT-DWG-20260920-001`
- 图纸名称：`审计走查·控制柜接口图`
- 图纸类型：装配图
- 所属分类：机械图
- 所属部门：默认部门
- 备注：审计走查用途

点击「保存草稿」后，页面返回 `密级不合法：GENERAL 不在字典中或已停用`；保密等级下拉同时显示
「暂无数据」。页面默认值虽然是 `GENERAL`，但当前租户字典不接受该值。保存没有成功，RISEMAP 未新增
任何单据；本轮也未删除、作废、撤销或改写历史数据。

该实时表现与旧证据中的「普通 / 秘密 / 机密」选项冲突，按项目规则以当前页面为准。密级字典恢复前，
RISEMAP 同材料成功链保持待复核，不用 Forge 自己的验收材料替代。

## Forge 本轮实现

- 图号对象补齐 RISEMAP 当前 12 种图纸类型、10 种分类，并兼容已有历史枚举值。
- 补齐图纸简称、关键零件、按图采购、允许旧版本替代及替代条件、进料检验、首件确认、可委外、
  批次追溯字段；复用已有受控编号/份数、版本管理、物料/项目/供应商关联。
- 新建图号弹窗补齐上述字段、选择器、规则开关和条件校验。受控图纸必须填写受控编号与有效份数，
  允许旧版替代时必须填写替代条件。
- 修复新建弹窗供应商选择器未加载供应商数据的问题。
- 文件资源树从占位说明改为真实图纸清单，并提供每行「查看属性」入口。
- 发布列表和 CSV 补齐本次发布版本、发布前版本、版本链路、审核通过时间、影响对象数。

## Forge 业务验收

隔离运行实例：`http://localhost:4517`；数据库：
`.objectstack/acceptance/drawing-replication-20260920.sqlite`。

通过项：

1. 图号档案字段、受控份数及八项业务规则创建后回读一致。
2. 匿名提交被拒绝；完整版本可送评，意见必填，评审通过后才能发布。
3. 发布前阻断、发布审批、正式发布、未发布单取消及取消原因均生效。
4. 工程变更必须关联变更后版本；影响未处置时禁止完成。
5. 项目、物料、BOM、采购订单、组装单五类引用冻结版本；新版发布后主数据可生成替代链，
   采购与组装交易仍保留原版本。
6. 单接收对象确认和回执可办理；多人发放区分全部确认与任一确认门槛，逐人回执聚合到父单。
7. 客户图纸草稿可保存、续填、提交为有效状态。
8. 内置浏览器实际完成质量工程师接收确认、项目关联采纳 V1.1、第二接收对象确认并回执；
   页面分别回读为「全部已确认」和「2 / 2 已确认、已回执」。
9. 完整停服并用同一 SQLite 重启后，生命周期、五类关联冻结历史、多人确认回执、客户图纸草稿链
   均按原 ID 回读通过；数据库完整性检查结果为 `ok`。

工程门禁：`pnpm typecheck`、`pnpm validate`、`pnpm build` 全部通过。`validate` 与运行时仍输出项目既有的
平台保留字段存储属性警告，这些警告不来自本轮图纸对象字段，也未造成图纸元数据解析或业务链失败。

## 验收边界

- Forge 本轮已完成实时证据支持的实现与单侧业务验收。
- RISEMAP 当前密级字典阻断同材料落单，因此不能声明 RISEMAP 与 Forge 双侧业务验收通过。
- RISEMAP 明确未开放或当前页面未证明的采购/BOM/项目编号反向追溯、高级导入导出、批量操作和多阶段审签
  不包装成已完成能力；页面上不提供无结果的假按钮。
- `tests/page-polish.manifest.json` 中图纸页面继续保持 `review_required`，等待 RISEMAP 环境恢复后的同材料复核。
