# 委外配置页面合同

## 范围

- RISEMAP：`https://risemap.cn/settings/business/subcontract`
- Forge：`/_console/apps/forge/page/page_subcontract_business_config`
- 原型：配置型页面
- 岗位：委外管理员、采购与生产协同人员

## RISEMAP 当前事实

- 页面包含委外字典分组，以及加工类型、退料原因、委外规则、预警阈值、业务策略五类配置入口。
- 加工类型最多两级，是供应商工艺能力、加工价目和委外订单加工件的匹配键；已被引用的类型不能删除，只能停用。
- 2026-09-21 实时核对时，当前加工类型“审计走查·钣金加工”已被引用 2 次。

## Forge 实现

- 默认进入加工类型，六类配置均可切换、搜索、刷新，并支持新增、编辑、删除和启停。
- 加工类型支持一级/二级父子关系；规则、阈值和策略支持配置值。
- 页面已使用当前认证适配器；加工类型、退料原因及规则数据可在同一 SQLite 重启后回读。
- Forge 的删除弹窗提供不可恢复提示；具体引用阻断仍由对象关系与业务服务负责。
