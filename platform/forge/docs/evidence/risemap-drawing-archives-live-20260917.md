## 台账模式（2026-09-17 补证）

来源：`docs/references/risemap-capture/deep/production/drawing/rm-074/` 的 2026-09-09
实时抓取（846 台账、847 类型筛选、848 状态筛选、849 受控筛选、850 更多筛选、851 布尔选项、
852 导入、853/854 导出任务、855/856 列设置、859 至 865 高级筛选），并与用户 2026-09-17
提供的台账模式截图逐项核对一致。本页地址 `https://risemap.cn/drawing/archives`，
档位为「台账模式」，租户台账为空态。本批未对 RISEMAP 执行任何写操作。

- 模式开关是单选：`文件资源树`（Value 0）/ `台账模式`（Value 1，选中态）。
- 指标条 6 项：图纸总数 / 已发布 / 待评审 / 已评审 / 变更中 / 已作废；数字各自着色
  （已发布绿、待评审琥珀、已评审靛、变更中紫、已作废红），空态全部为 0。
- 动作行：`新建图号`（主按钮）、`批量导入`、`导出`、`任务列表`、一个图标按钮、`刷新`、
  两个图标按钮；右侧无独立搜索框。
- 筛选行：搜索框（占位「搜索图号、名称...」）、`图纸类型` ▾、`图纸状态（全部 0）` ▾、
  `所属分类` ▾、`受控标识` ▾、`关联项目`；第二行为 `重置` 与 `展开更多筛选` ▾。
  - 图纸类型选项：装配图、零件图、电气图、原理图、布置图、安装图、施工图、P&ID 图、
    控制图、网络拓扑图、流程图、说明书。
  - 图纸状态选项：草稿(0)、待评审(0)、评审中(0)、已评审(0)、审批中(0)、已审批(0)、
    已发布(0)、变更中(0)、已作废(0)。
  - 受控标识选项：受控、非受控。
- 表头共 14 列：勾选框、图号、图纸名称、图纸类型、所属分类、当前生效版本、图纸状态、
  受控标识、关联物料、是否关键件、是否按图采购、关联BOM数、最近更新时间、操作。
- 空态文案：`未找到匹配的图号档案，请调整筛选条件重新查询`。
- 分页：`共 0 条记录 每页 [10] 条 上一页 1 下一页`。
- `展开更多筛选` 展开为「高级筛选」面板（多条件 AND、可加条件、可清除全部，
  操作符含 等于 / 不等于 / 属于其中任一 / 不属于其中任一 / 为空 / 不为空）。
- 列设置面板显示 `已显示 12 / 39 列`，保存后提示「列设置已保存」。

### 台账模式下 Forge 与 RISEMAP 的差异（本批处理）

| 部位 | RISEMAP 实时事实 | Forge 本批处理 |
| --- | --- | --- |
