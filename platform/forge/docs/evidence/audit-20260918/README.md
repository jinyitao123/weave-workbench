# Forge 供应链 ↔ RISEMAP 全量结构对照审计

## 覆盖范围
RISEMAP 供应链全部 42 个页面（到货检验 5 / 基础资料 7 / 采购管理 7 / 入库管理 6 / 库存管理 10 / 出库管理 7），
Pages 与 RISEMAP 一对一映射（RISEMAP 路径见 risemap-facts.json）。

## 方法
1. 内置浏览器固定 1280 宽，逐页同时截 RISEMAP 与 Forge 截图：`<页面>-risemap.png` / `<页面>-forge.png`。
2. 同一口径抽取两侧可比较的结构事实：hero（标题/描述/下一步磁贴/当前环节提示）、工具条按钮（含「图标 or 文字」判定）、
   页签、筛选控件占位、首张列表的表头列、首行行操作（图标 or 文字）、指标卡数量。原始数据见 `risemap-facts.json` / `forge-facts.json`。
3. 自动比对生成 `AUDIT.md`（逐页差异）与 `SUMMARY.md`（按差异类型归纳）。

## 结果
- 42 页中 41 页存在结构差异，差异点 201 条。
- 差异分类：Forge 多出按钮 54 / RISEMAP 独有按钮 31 / 筛选文案 28 / 列表列 23 / **图标按钮被写成文字按钮 21** /

## 几何（组件位置大小）对照

除结构对照外，本轮还做了同宽 1280 的几何测量（hero 盒子、内容卡片宽度、表格宽度、表头行高、列数与列宽、工具条按钮高度），
结果见 `GEOMETRY.md`，原始数据 `risemap-geometry.json` / `forge-geometry.json`。据此修复了共享组件的三处尺寸差异：

- hero 标题字号 27px → 22px（RISEMAP 21px），42 页标题字号差异归零
- 工具条图标按钮 32×32 → 28×28（RISEMAP 27×27）
- 文字按钮高度 34px → 32px（RISEMAP 32px）
- 列表表头行高 39px → 53px（RISEMAP 53px），含 15 个仍用旧 `.table` 样式的页面

仍存在的几何差异：内容卡片宽度（外壳侧边栏宽度不同，37 页）、列宽分布（18 页）、列数（22 页）、到货通知表头换行（71 vs 35px）。
