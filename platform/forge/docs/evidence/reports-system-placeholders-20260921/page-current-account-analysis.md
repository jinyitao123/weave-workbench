# 往来账款占位清理记录

## 页面合同

- pageId：`page_current_account_analysis`
- RISEMAP 入口：`https://risemap.cn/finance/statistics/current-account`
- Forge 入口：`/_console/apps/forge/page/page_current_account_analysis`
- 页面职责：按应收与应付两个视角展示未核销余额、账龄、近期到期、收付款与采购预付。
- 岗位：应收会计、应付会计、财务负责人、经营负责人。
- 主单据：应收账款、应付账款、实际收款、实际付款、供应商预付款。
- 主原型：`analysis`；以 RISEMAP 当前往来账款页面为直接结构基线。
- 首屏顺序：标题及导出 → 应收/应付页签 → 期间筛选 → 实时汇总说明 → 四项指标 → 账龄或近期到期明细。
- 主动作：切换应收/应付、切换统计周期、打开指标口径说明、导出、进入应收应付台账。

## 2026-09-21 RISEMAP 当前事实

- 已在登录态内置浏览器通过“报表 → 财务统计 → 往来账款”进入当前页，真实 URL 为 `/finance/statistics/current-account`；应付页签会增加 `?section=payable`。
- 标题为“往来账款”，说明为“客户应收、账龄结构和供应商应付分析”，标题动作是“导出PDF”“导出Excel”。
- 两个视图为应收分析和应付分析；筛选当前为本季度，页面说明财务数据按业务单据实时汇总并显示统计周期。
- 应收分析显示应收余额、逾期金额、回款率、最长逾期；下方依次为应收账龄结构、逾期客户明细和账龄区间明细。账龄区间为未到期、1-30天、31-60天、61-90天、90天以上。
- 应付分析显示应付余额、30天内到期、本季度资金流出、采购预付和近期到期供应商。当前 RISEMAP 应付余额与 30 天内到期均为 `36,720.00`，包含南京锐联电气技术有限公司两笔 2026-10-17 到期记录。

## 修改前 Forge 差异与实现边界

- 修改前导航指向通用 `page_reports_gap`，只展示报表入口目录，没有任何应收应付指标、页签、期间筛选、账龄、到期供应商或业务数据。
- Forge 实现只汇总当前持久库内未取消、未作废、未撤销且余额大于零的应收、应付和供应商预付款；统计周期资金流出读取有效实际付款。
- 账龄按当前日期与到期日的日历天差计算；回款率按有效应收累计已核销金额除以应收原值计算。以上为 Forge 可复核计算，不把 RISEMAP 的线上材料或金额移植为 Forge 数据。
