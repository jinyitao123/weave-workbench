# 风险监控占位清理记录

## 页面合同

- pageId：`page_risk_monitoring`
- RISEMAP 入口：`https://risemap.cn/finance/statistics/risk`
- Forge 入口：`/_console/apps/forge/page/page_risk_monitoring`
- 页面职责：集中展示逾期应收、近期应付、库存占用、预付未结风险，提供往来集中度和数据对账入口。
- 岗位：财务负责人、应收会计、应付会计、库存会计、经营负责人。
- 主单据：应收账款、应付账款、供应商预付款、库存余额、客户和供应商。
- 主原型：`analysis`；以 RISEMAP 当前风险监控页面为直接结构基线。
- 首屏顺序：标题及导出 → 财务预警/集中度分析/数据对账 → 期间筛选 → 实时汇总说明 → 指标卡 → 风险明细、分布或对账入口。

## 2026-09-21 RISEMAP 当前事实
