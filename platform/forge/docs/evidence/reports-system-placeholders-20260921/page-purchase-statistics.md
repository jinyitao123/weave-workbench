# 采购统计占位清理记录

## 页面合同

- RISEMAP 入口：`https://risemap.cn/reports/purchase`
- Forge 入口：`/_console/apps/forge/page/page_purchase_statistics`
- 页面职责：按订单、供应商、采购负责人和时间范围查看采购额、入库、应付、执行阶段与排行。
- 岗位：采购负责人、采购主管、经营分析人员。
- 主单据：采购订单；关联采购申请、询价、到货、入库、应付和订单明细。
- 主原型：分析型；参考 `project-timesheet-cost.page.ts` 与共享 `product-ui.ts`。
- 主动作：筛选统计范围、刷新、导出当前结果、进入采购申请、询价和供应商页面。
