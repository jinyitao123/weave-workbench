# 组装统计占位清理记录

## 页面合同

- pageId：`page_assembly_statistics`
- stateId：`populated-analysis`
- RISEMAP 入口：`https://risemap.cn/reports/assembly`
- Forge 入口：`/_console/apps/forge/page/page_assembly_statistics`
- 页面职责：分析组装、领料、补料、退料、拆解与换件的规模、完成进度、阶段转化、负责人、成品/物料和车间效率。
- 岗位：生产主管、车间负责人、物料员、经营分析人员。
- 主单据：组装单、生产领退补料单、生产入库单、拆解单、换件单。
- 主原型：`analysis`；实现参考 `inventory-statistics.page.ts` 与共享 `product-ui.ts`，最终几何与视觉以 RISEMAP 当前页为准。
- 首屏区块顺序：标题与导出 → 六个业务页签 → 搜索/车间/周期/刷新 → 更新时间与口径 → 四项指标 → 趋势与分布 → 阶段转化与负责人排行 → 业务对象排行与车间对比。
- 当前主动作：切换统计维度、按单号/成品/负责人搜索、按车间和周期筛选、刷新、导出当前维度结果。
- 来源关系：组装单承接 BOM 与销售订单；领退补料单关联组装单；生产入库单关联组装单；拆解与换件单独立承接成品、BOM、仓库和责任人。
- 下一步入口：组装生产工作台、生产领退补料工作台、拆解与换件工作台。

## 修改前 Forge 基线与明确差异

- `assembly_statistics` 当前指向共用 `page_reports_gap`，只显示“报表业务入口”和十一项文本目录。
- 当前 Forge 没有六页签、筛选、指标、趋势、分布、阶段转化、排行、导出或对应生产数据回读，属于真实占位页。
