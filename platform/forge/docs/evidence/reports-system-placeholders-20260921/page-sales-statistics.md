# 销售统计占位清理记录

## 页面合同

- RISEMAP 入口：`https://risemap.cn/reports/sales`
- Forge 入口：`/_console/apps/forge/page/page_sales_statistics`
- 页面职责：按订单、客户、销售负责人和时间范围查看销售额、订单、回款、履约与排行。
- 岗位：销售负责人、销售主管、经营分析人员。
- 主单据：销售订单；关联销售合同、发货、应收和订单明细。
- 主原型：分析型；参考 `project-timesheet-cost.page.ts` 与共享 `product-ui.ts`。
- 主动作：筛选统计范围、刷新、导出当前结果、进入其他销售分析维度。
- 下一步：从维度页进入销售合同、线索、商机、跟进、报价、客户和毛利页面继续分析。

## 布局与控件检查

- 1440×900：标题、页签、筛选、四指标、趋势、状态与三组排行均可见，无按钮或输入框重叠。
- 760×900：标题动作改为整行；筛选重排为搜索整行、组织与周期双列、刷新单列；指标与排行改单列。

## 差异与状态

- RISEMAP 当前内容区在窄内容宽度下将指标卡纵向排列；Forge 在标准桌面内容宽度下四列、窄屏下单列，属于响应式断点差异，尚未形成保存到仓库的叠图/像素差异结果。
- Forge 的其他维度按钮进入已有独立业务页面，而非在同页伪造未实现图表；这是 Forge 产品实现决策。
- 本页已清除菜单占位并完成真实数据读取和主要筛选交互，但视觉状态仍为 `review_required`，不得写成像素验收通过。
