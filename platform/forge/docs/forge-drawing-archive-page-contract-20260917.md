# Forge 图号档案页面合同（2026-09-17）

依据 `docs/forge-page-delivery-standard.md` 与 `docs/forge-page-polish-baseline.md`。
本轮起因：基线原先禁止标题区使用渐变、色块与装饰图，导致 Forge 的「图号档案」与
RISEMAP 呈现差距过大。用户已决定放开该限制，本文件据此重定该页范围。

第二轮补入 RISEMAP 的「台账模式」视图：该模式的列、筛选、指标与分页以
`docs/evidence/risemap-drawing-archives-live-20260917.md` 记录的 RISEMAP 实时事实为准，
Forge 决策单独列在「台账模式设计决策」一节。

## 批次和范围

- 本批业务链：图纸管理 → 图号档案（`page_drawing_archive`）。
- 全量范围来源：导航（生产 → 图纸管理）、页面注册（`src/pages/index.ts`）、
  `tests/page-polish.manifest.json`、`drawing-workspace.page.ts` 现有 9 个图纸页签。
- 本批具体页面：`page_drawing_archive`。同文件中的图纸总览、版本台账、图纸评审、
  图纸发布、图纸变更、发放记录、关联查询、客户图纸不在本批范围，保持现状。
- 排除项及理由：其余 8 个图纸页签仍由共享生成器产出，属“只替换标题/页签/列”的
  批量页面，按基线保持 `review_required`，另行成批精修。
- 共享文件唯一负责人：`apps/forge-objectstack/src/pages/product-ui.ts`（页面共享
  样式与运行时）。本页新增 hero、模式工具栏、左树与属性面板，均先落在该文件。

## 视觉基线变更（本批前提）

基线第 2、9 节已放开“禁止渐变/装饰”：

- 标题区允许两种形态，同页只用一种：纯文字标题区，或**品牌标识区（hero）**。
- hero 使用品牌渐变或品牌底色，含图标徽章、业务面包屑、标题与一句职责说明，
  右侧可放线稿装饰图；高度约 `150px` 至 `200px`，文字反白。
- hero 只承担页面标识，不放业务数据、指标、表单或按钮；一页只允许一个 hero。
- 渐变与装饰图只允许出现在 hero；主工作区仍为中性色加主按钮。

## 逐页设计

- pageId / RISEMAP 当前入口 / Forge 入口：
  `page_drawing_archive` / RISEMAP 生产 → 图纸管理 → 图号档案 /
  Forge `/_console/apps/forge/page/page_drawing_archive`。
- 岗位 / 核心任务 / 主单据 / 来源 / 下一岗位：
  图纸管理员 / 维护图号档案与图纸文件访问范围 / 图号档案（`forge_drawing`）/
  图纸评审与发布 / 版本台账。
- 主原型 / 选择理由 / 参考源文件：
  任务执行型（tree + list 工作区）/ 该页是“左目录树 + 右清单 + 底部属性”的
  办理型页面，不是通用列表页 / 参考 `project-task-workspace.page.ts`，
  RISEMAP 当前页截图（用户 2026-09-17 提供）。
- 首屏区块顺序：
  hero 标识区（面包屑「图纸管理 › 图号档案」+ 图标徽章 + 标题 + 一句说明）→
  模式开关（文件资源树 / 台账模式）→
  文件资源树模式：左「文件目录」树 + 右「全部图纸」清单 + 底部「属性信息」面板；
  台账模式：6 项指标条 → 动作行（新建图号 主按钮 / 导出 / 刷新）→ 筛选行
  （搜索 + 图纸类型 + 图纸状态 + 所属分类 + 受控标识 + 关联项目 + 重置）→
  宽表（11 列）→ 分页条。
- 主动作与位置：`新建图号` 为工具栏唯一蓝色主按钮；批量导入、导出、任务列表为
  次按钮；刷新为图标按钮。搜索框位于左树面板内，不再占用标题行。
- 全局范围与局部筛选作用对象：左树的面板级开关（档案模式 / 权限管理）切换树的
  口径；树内搜索只过滤目录，右清单保持按选中节点过滤。
- 指标口径与追溯：RISEMAP 本页不设指标卡。Forge 现有 4 张 KPI 卡
  （图号档案 / 已发布版本 / 待版本复核关联 / 待处置影响）与本页任务无直接关系，
  按基线“没有口径或与当前任务无关的指标应删除”，本批移除。
- 字段和列顺序：台账模式按 RISEMAP 台账表 14 列取值，Forge 实现其中 11 列 ——
  图号、图纸名称、图纸类型、所属分类、当前生效版本、图纸状态、受控标识、关联物料、
  关联项目、最近更新时间、操作。RISEMAP 的 是否关键件 / 是否按图采购 / 关联BOM数
  在 `forge_drawing` 与 `forge_material` 都没有对应字段，列为缺口，不用空列或占位值顶替。
- 状态/联动/阻断/提交反馈/下一步：沿用现有对象与 Action，不新增业务规则；
  提交后回读页面状态，失败在当前上下文显示原因。
- 桌面与窄屏视口：桌面 1440×900 与 1280×720；窄屏 390×844。窄屏下 hero 高度
  收缩、模式工具栏换行、左树与右清单改为上下堆叠。

## 台账模式设计决策（Forge 侧）

RISEMAP 台账模式下租户为空态，行内容与行操作没有可取证事实。以下均为 Forge 决策，
与合同上文的「RISEMAP 已观察事实」分开记录：

- 指标口径按 Forge 数据推导，以图号档案条数计数：图纸总数 = 全部图号；
  已发布 = `forge_drawing.status='released'`；待评审 = 存在 `pending` 评审单的图号；
  已评审 = 存在 `approved` 评审单的图号；变更中 = 存在 `pending` / `approved` /
  `implementing` 变更单的图号；已作废 = `forge_drawing.status='obsolete'`。
- 列表默认每页 10 条，与 RISEMAP 台账一致；搜索框匹配图号与图纸名称。
- 图纸状态筛选使用 `forge_drawing` 的真实状态集合（草稿 / 评审中 / 已发布 /
  已作废 / 已归档），不照搬 RISEMAP 的九级生命周期文案，避免出现选不中的选项。
- 导出为当前筛选结果的 CSV 下载，对应 RISEMAP 的「导出」入口；RISEMAP 侧生成
  后台导出任务，Forge 用前端下载承载，属产品决策差异。
- 行操作 查看 打开只读属性面板，面板内提供 上传新版本、发起图纸变更（仅已发布图号）、
  查看版本台账 三个真实入口。RISEMAP 台账行操作内容未取证。
- 未实现且不放置占位控件：批量导入、任务列表、展开更多筛选（高级筛选）、列设置、
  行勾选与批量操作、是否关键件 / 是否按图采购 / 关联BOM数 三列。

## 未决与证据边界

- 内置浏览器后端仍持续报 `Unable to load browser request-header policy`，RISEMAP 侧
  证据来自 `docs/references/risemap-capture/` 的实时抓取文件与用户 2026-09-17 截图，
  两者结构一致；本条不改变摘取口径，仍写明来源与取证时间。
- RISEMAP 台账模式下租户为空态，行内容、行操作与批量操作没有可观察事实，
  对应实现只能算 Forge 决策，不能称“已复刻”。
- 本页仍为 `review_required`：树模式与台账模式的 Forge 侧已在内置浏览器逐项操作并回读
  （`docs/evidence/drawing-archive-ledger/`），但 RISEMAP 侧无法在同一组业务数据上
  并排办理，因此不得称“已对齐”或“验收通过”。
