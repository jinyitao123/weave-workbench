# 库存流水页面合同

日期：2026-09-15

## 入口与职责

- RISEMAP：`https://risemap.cn/inventory/flow`
- Forge：`/_console/apps/forge/page/page_inventory_ledger`
- 岗位：仓库、财务、采购、生产与审计人员。
- 职责：只读追踪所有库存变动和来源单据，按月份、仓库和出入库方向汇总。

## RISEMAP 当前事实

- 标题为“库存流水”，说明为“查看所有出入库流水记录与数据报表”。
- 一级视图为库存流水、报表。
- 流水视图包含导出、含税金额合计、刷新；筛选为物料名称/编码/型号、事务号/流水号、批次/SN、类型、仓库和开始/结束日期。
- 明细列为流水号、类型、业务类型、日期、仓库、库位、物料名称、型号、SKU 编码、规格、批次、SN、外部 SN、操作人、数量、关联单号、对方，分页每页 20 条。
- 报表视图显示本月入库总额、本月出库总额、本月入库笔数、本月出库笔数、月度趋势和仓库维度统计。
- 当前租户有 5 条流水，金额 ¥54,000，来自采购在途和期初入库。

## Forge 实现决定

- `forge_inventory_ledger` 是业务动作自动写入的审计账，专用页不提供新建、导入、编辑或删除入口。
- 明细关联仓库、SKU、物料、单位、用户、来源单据和可证明的来源明细；源数据没有库位、批次或 SN 时显示 `—`。
- 关联单号跳转到真实来源业务页；无法确定的来源保持只读文本。
- 报表由当前真实流水按月份、仓库、方向和金额聚合，不保存静态统计。

## 验收材料

- 两侧内置浏览器双视图、筛选、来源跳转和分页。
- Forge API 对流水、仓库、SKU、来源和前后数量的同一 SQLite 重启回读。
- `pnpm typecheck`、`pnpm validate`、`pnpm build`、页面控件可用性检查。
