# 采购检验单页面合同

日期：2026-09-16

## 页面职责与原型

- RISEMAP：`https://risemap.cn/inventory/inspection`；Forge：`page_purchase_inspection_workspace`。
- 岗位：来料质检员；主单据：单物料检验单；主原型：任务执行型，参考 `task_workspace` 与 `ForgePageHeader`。
- 首屏顺序：页头与下一步 → 搜索筛选 → 检验单列表 → 分页；详情完成合格数量和检验结论。
- 下一步：采购入库。

## RISEMAP 当前事实

- 每张检验单对应一种物料；列表列为检验单号、到货单号、物料、供应商/客户、方式、总/合格/不合格数量、结果、状态、检验员、到货日期、操作。
- 提供状态、结果、方式、供应商和到货日期范围筛选；当前租户为空。

## Forge 实现与未决项

- Forge 支持全检/抽检、合格数量、自动计算不合格数量和合格/部分合格/不合格结果；总数量必须等于合格与不合格之和。
- 检验项目逐项录入依赖检验规则后续扩展，本轮不以文本结论替代已观察的项目库能力。

## 验收材料

- 验证数量上下界、结论必填、完成后状态和结果回读、进入采购入库、筛选与窄屏布局。
