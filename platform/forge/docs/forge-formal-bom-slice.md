# Forge 正式 BOM 流转切片

更新于 2026-09-10。本切片承接同一笔 OEM 控制柜项目，把已有草稿 BOM 变成可评审、可生效、可派生项目版本且可追溯的正式制造输入。

RISEMAP 同材料标准 BOM `BOM-RM-CAB-800-V1` 已实际完成提交评审、同意并生效为 `V1.0`，包含 PLC、触摸屏、电源和柜体四项物料，未税成本 `14442.48`。生效后的页面提供复制到新版本和失效动作；项目 BOM 派生表单要求客户与适用项目，并继承标准结构。远端项目 BOM 表单只完成观察，没有保存，因此不把项目派生终态写成 RISEMAP 对照通过。

Forge 增加标准与项目 BOM 生命周期、版本族与来源、项目和客户关联、物料数与成本快照、提交与生效信息，并用独立审批日志保存提交、同意、退回、复制和失效。提交评审按结构重新计算四项物料及成本；生效后结构字段只读。已生效标准版本可复制为 `V1.1` 草稿，也可派生项目 BOM；同一项目存在有效或待处理版本时阻止重复派生。

定向 API 验收共 10 项。真实浏览器从已生效标准 BOM 派生 `PRJ-2026-002` 项目 BOM，提交评审、填写意见并同意，页面回读来源、项目、客户、版本、物料数、成本、生效时间和评审人。正式入口改为专用 BOM 工作台，按 RISEMAP 证据实现面包屑、标题与状态、状态相关动作、七个业务页签、版本切换栏和紧凑字段区；BOM 结构、版本历史及审批日志直接读取持久数据，未实现页签在页面中明确标为待复核。最终验收在端口 `4346` 的独立 `.objectstack/otc-formal-bom-final-20260910b.sqlite` 从草稿重新执行全部动作，随后完整停服并从同一文件重启；标准 BOM、主项目 BOM、浏览器项目 BOM、失效 `V1.1`、结构节点和审批日志均按原 ID 回读，专用页面刷新后仍为已生效。

浏览器视觉对照使用 RISEMAP `基础资料 / BOM管理 / 新建BOM` 的同材料页面。Forge 已对齐标题状态节奏、主动作位置、七页签名称与顺序、两列字段布局和灰色工作区层级；ObjectStack 自带的顶部工具栏与阶段式左侧导航保留为 Forge 产品壳层。左侧导航按汇川 OTC 九阶段组织，`集成调试与验收` 和 `结项经营复盘` 当前只提供项目上下文入口，不据此声称对应业务已实现。

缺料分析、图纸关联、版本替代、归档与删除、BOM 对比、真实附件、导入导出以及生产引用锁定仍需后续实现和验证。
