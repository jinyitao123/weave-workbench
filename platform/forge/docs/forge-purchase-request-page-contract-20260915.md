# Forge 采购申请逐页原型合同

## 页面与证据

- RISEMAP 入口：`https://risemap.cn/purchase/requests`
- RISEMAP 新建入口：`https://risemap.cn/purchase/requests/new`
- Forge 入口：`http://localhost:4386/_console/apps/forge/page/page_purchase_request_pool`
- 实时证据日期：2026-09-15，内置浏览器 DOM 与首屏截图。
- 设计状态：`review_required`。完成代码、工程门禁或单侧浏览器验证都不能把本页称为已精修。

## 逐页原型

- 主原型：`task_workspace`
- 参考页面：`project-task-workspace.page.ts`
- 选择原因：申请人围绕一张采购申请完成建单、明细、提交和回看，审批人继续处理后进入采购待办；页面的主任务是推进单据状态，不是经营分析。

## RISEMAP 已观察事实

- 首屏标题为“采购申请”，说明为“发起采购申请、审批流转、转询价/订单全流程跟踪”，右侧存在“下一步操作 采购待办池”。
- 双视图为“申请列表”和“物料明细”。工具栏包含新建申请、导入/导出、刷新、搜索、状态筛选、日期范围和分页。
- 申请列表列为申请编号、申请标题、优先级、关联项目、关联客户、负责人、物料数、总数量、预估含税金额、币种、期望到货日期、建议供应商、采购原因、备注、状态、申请日期和操作。
- 新建页已观察到直接新建、保存草稿、提交审批；基本信息包括申请编号、标题、优先级、项目、客户、币种、只读申请日期、期望到货日期、负责人、建议供应商、采购原因、附件和备注。
- 采购明细支持物料库选择、手动添加、快速粘贴、Excel 导入、物料组合和关联销售订单；当前空态提示至少通过其中一种方式添加明细。
- 当前 RISEMAP 租户列表为空，已保存草稿的编辑、审批弹窗、驳回、取消以及转询价/订单结果尚未通过同材料观察。

## Forge 页面顺序

1. 标题与当前职责，右侧提供导出、刷新和“新建申请”主动作。
2. “下一步操作 采购待办池”明确采购人员的后续入口。
3. 申请列表/物料明细页签。
4. 搜索、状态和日期范围筛选，只作用于当前工作区。
5. 主列表显示与 RISEMAP 相同的申请字段；行操作按状态显示查看、编辑、提交、审批、驳回、取消或进入采购待办。
6. 新建/编辑使用标准弹窗录入基本信息和多条物料，先保存草稿；提交、驳回和取消使用标准二次确认。
7. 列表底部显示记录数和分页；加载、错误和空数据均显示明确反馈。

## 当前主动作与阻断

- 申请人主动作：新建申请并保存草稿，随后提交审批。
- 审批人主动作：审批通过或填写原因驳回。
- 草稿必须有申请编号、标题、期望到货日期、负责人、采购原因和至少一条正数物料明细。
- 只有草稿或已驳回状态可编辑、提交和取消；审批中不可编辑；审批通过后进入采购待办。
- 取消后保留只读记录和明细，不可恢复或继续提交。

## Forge 决策与未决项

- Forge 增加取消二次确认，明确显示单号、物料数量、影响和不可恢复结果。
- 附件存储尚未接入，因此只显示能力说明，不提供假上传按钮。
- 第一版支持从已有物料 SKU 选择多条明细；快速粘贴、Excel 导入、添加物料组合、关联销售订单和文件附件保持未实现，不包装成可点击入口。
- RISEMAP 当前无可办理申请，状态文案、审批意见要求和转询价/订单的细节仍待同材料复核。
