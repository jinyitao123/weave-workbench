# Workbench 中以对话为先的能力创建

[English](2026-09-13-capability-development.md) | 中文

可复用能力沿用既有团队交互方式。智能体先列出已发布能力，合适时直接复用，否则把业务需求交给 Weave 生成并保存草稿。对话用用途、职责、流程、输入和输出供用户审查，不展示 JSON 编辑器、schema、角色标识或执行内部细节。

创建草稿需要调用方提供幂等键。结果不确定时使用同一键重试，因此仍指向同一草稿。发布是独立工具调用，只有用户确认准确方案并同意发布后才可执行。已发布版本不可修改，后续变化生成新的草稿版本。

能力是工作空间中的组织资产。数据库读写包含工作空间身份，创建和发布需要能力管理权限。当前桌面 Host 代表一个已配置的开发者身份。多人共享 Host 时必须传递每个用户的委托凭据，才能声称完成了个人归属。

应用访问设置保持独立，管理稳定应用标识、限定范围的密钥和精确版本授权。应用凭据使用独立令牌前缀，不能访问普通平台或能力创建路由。Host 保管自己的密钥；签发的应用密钥只显示一次。浏览器验收覆盖创建、精确版本授权、轮换、吊销和结果回读。
