# 品牌视觉与登录页设计

更新：2026-10-07。适用：Forge 登录页（ObjectUI 控制台的认证页面）、桌面端应用图标。当前处于原型阶段，尚未进入组件源码，也没有生成正式素材。来源为旧候选 `97b058691d6ae088aebf8d01bb906b7a0ed3b1d2`；本轮只归并参考，品牌、色调和布局均不构成已批准决定。

## 范围与边界

- Forge 登录页的代码在 ObjectUI 分叉的 `apps/console/src/pages/auth/AuthLayout.tsx`。登录、注册、找回密码、首次初始化都共用这一个布局，Forge 通过 `platform/forge/apps/forge-objectstack/console94.lock.json` 锁定它的构建产物。本文只定设计和素材；实现回 ObjectUI 来源仓，再按[开发与发布方式](开发与发布方式.md)更新 Forge 和总仓的版本锁。
- 桌面端图标在 `desktop/assets/`：macOS 用 `icon.icns` 和 `icon.iconset/`，Windows 和 Linux 用 `icon.png`。
- 页面文案遵守 [AGENTS.md](../../AGENTS.md#开发规则)：只放标题、字段、操作和必要提示，不放标语；视频和图片里也不出现文字。
- 不模仿任何其他公司的品牌字体、配色或标志；外部产品只作为"克制、慢动效"这一做法的参考。

## 当前方向

原型：[Forge登录页原型](assets/Forge登录页原型.html)。在本地浏览器打开即可，右上角的方向和色调切换只属于原型。

- **色调**：候选建议雾白，是否采用待用户确认，与 Forge 页面的浅灰蓝底 `#f5f7fb` 同调，进入系统后的视觉衔接最自然。墨蓝保留为备选。
- **布局**：A 分栏（左边表单，右边动态面板）和 B 全屏（背景铺满，卡片居中）尚未定稿，原型默认 A。窄屏下 A 隐藏动态面板，只留表单。
- **表单**：沿用 Forge 的颜色变量——正文 `#172033`、主按钮 `#245bdb`（悬停 `#1948bb`）、输入框边框 `#dfe3ea`；控件高 44px，圆角 10px，标题 30px；字体沿用 Forge 的系统字体栈。
- **品牌标识**：当前的"F"图形是占位，正式 Logo 按下文流程产出后替换。

上一版用了"发光粒子 + 正弦光带 + 饱和电光蓝"，被评价为土。这类模板化的科技感背景不再使用。后续素材都按这几条：大块柔和色域、低饱和、动得很慢、带细颗粒质感。

## 动态背景的视频位

没有视频素材时，用着色器实时绘制雾面流动画面作为默认效果和降级方案；有视频素材后，视频淡入覆盖在上面。原型已实现这套切换，用地址参数试播：`Forge登录页原型.html?video=login.webm&poster=poster.webp#a-mist`。

| 项目 | 规格 |
| --- | --- |
| 播放方式 | 静音、自动播放、循环、`playsinline`；先垫封面图，视频可播放后用 0.8 秒淡入，避免黑屏闪一下 |
| 降级 | 系统开启"减少动态效果"时只显示封面；标签页切到后台时暂停；视频加载失败时继续显示着色器画面 |
| 暂停按钮 | 面板右下角，带可访问名称；自动播放超过 5 秒的动画必须能暂停 |
| 画面比例 | 按 16:9 生成。A 布局在 1440×900 下面板接近 1:1，会裁掉两侧，所以主要的视觉变化要放在画面中间约 55% 宽度以内 |
| 时长 | 8–10 秒无缝循环，24 或 30 帧，不带音轨 |
| 编码与体积 | WebM（VP9）不超过 3MB，MP4（H.264，`faststart`）不超过 4MB，封面 WebP 不超过 150KB，宽度 1920 |
| 画面内容 | 不出现文字、Logo、人物、具体物体、粒子、光斑、霓虹或科幻界面元素；高亮、低对比，不能抢了表单的视线 |
| 打包 | 客户内网部署不能引用外部地址，视频随控制台构建打包，放在 `/_console/brand/` 下 |

运维人员替换素材的配置入口尚未确定。现有运行配置的 `branding` 只有 `productName`、`logoUrl`、`faviconUrl` 三项；能否新增登录页素材字段、服务端是否会透传，需要在 ObjectStack 中核实后再设计，不能先在前端写死一个不存在的字段。

## 素材生产流程

1. **GPT Image 出图**：先出 Logo 候选，再出视频关键帧。每次 4 张，人工挑选。
2. **生成视频**：用选定的关键帧，通过即梦／火山方舟 Seedance 的首尾帧模式生成视频。首帧和尾帧用同一张图，生成结果天然接近无缝循环。也可以在即梦网页端手工操作：视频生成 → 首尾帧 → 首帧和尾帧上传同一张图 → 填同一段提示词 → 选镜头固定、低运动幅度、1080p，多生成几次挑选。
3. **后期处理**：用 ffmpeg 修补循环接缝、转码、截取封面（命令见下文）。
4. **人工审查**：看循环接缝是否有跳变、亮度是否压过表单、渐变处是否有色带、压缩痕迹、有没有出现文字或水印；在亮色和暗色系统、Mac 和 Windows 上各看一遍。
5. **采用前确认**：查清所用服务的商用授权条款；Logo 正式采用前做商标检索，并由设计师重绘成矢量 SVG。生成的位图只作为方案稿。

脚本 `tools/brand-media.mjs` 封装了这两个接口的调用，不依赖额外的包。密钥只从环境变量读取，不写进任何文件，也不打印到输出。生成的文件默认放在被 Git 忽略的 `.brand-media/` 目录下，每张图或每段视频旁边会保存一份当次用的提示词，方便复现。

```bash
node tools/brand-media.mjs image --model <已核模型ID> --prompt-file forge-mark.txt --size 1024x1024 --background transparent --n 4
```

```bash
node tools/brand-media.mjs image --model <已核模型ID> --prompt-file desktop-icon.txt --ref .brand-media/images/选定的Forge标志.png --size 1024x1024 --n 4
```

```bash
node tools/brand-media.mjs image --model <已核模型ID> --prompt-file login-keyframe.txt --size 2560x1440 --background opaque --format png --n 4
```

```bash
node tools/brand-media.mjs video --prompt-file login-motion.txt --first .brand-media/images/选定的关键帧.png --model <方舟控制台中的Seedance模型ID> --duration 10 --resolution 1080p --seed 42
```

接口草案未经本轮查询或真实调用验证。脚本保留图像生成／编辑与首尾帧视频的研究路径，模型必须通过 `--model` 或对应环境变量显式指定；不保证候选接口、参数或模型在供应商当前服务中可用。使用前另行核对正式文档、权限和费用，本次不调用素材 API。

## 提示词

GPT Image 对英文提示词的执行更稳定，所以出图提示词用英文；Seedance 对中文理解很好，视频提示词用中文。每段提示词都写明"不要什么"，这是避免画面变土的关键。

### Forge 标志（GPT Image，透明背景，1024×1024）

```text
Design a minimal brand symbol for "Forge", a business operations platform for engineering project companies
(sales, contracts, projects, approvals). Concept: something precisely shaped under structure and pressure —
two or three interlocking solid planes that suggest a folded steel sheet, an anvil face or a stacked ingot,
read as one confident geometric mark. Built on a strict grid with consistent corner radii.
Style: flat vector, crisp edges, at most one subtle tonal step between planes.
Colors: primary blue #245BDB with indigo #4051B5 as the secondary tone.
Composition: a single centered symbol filling about 60% of the canvas, generous empty padding, transparent background.
It must stay recognizable at 16×16 px.
Do not include: any text or letters, 3D rendering, glow, drop shadow, gradient mesh, sparks, flames, hammers,
gears, circuit lines, globes, or clip-art style.
```

### 循环视频（Seedance 首尾帧，首帧和尾帧用同一张关键帧）

```text
固定镜头，极其缓慢的画面。浅色丝绸般的薄雾在空气中轻柔流动，慢慢舒展、折叠又散开，柔和的光在褶皱之间缓缓移动，整体像平稳的呼吸。
保持原图的配色、亮度和构图，画面中央始终安静均匀。
不要推拉摇移，不要变焦，不要出现新的物体，不要文字和人物，不要闪烁，不要粒子和光斑，不要加速。
结尾回到与开头完全一致的画面，便于无缝循环播放。
```

参数：1080p，比例跟随首帧，时长取模型支持的 8–10 秒，关闭水印，固定 `seed` 以便复现；同一张关键帧换 3–4 个 `seed` 生成后挑选。

## 后期处理

首尾帧相同的视频在接缝处通常仍会有轻微跳变，可以把最后 1 秒交叉淡入开头来兜底。下面以 10 秒的源视频为例，`offset` 等于时长减 2：

```bash
ffmpeg -i raw.mp4 -filter_complex "[0:v]split[a][b];[a]trim=start=1,setpts=PTS-STARTPTS[main];[b]trim=end=1,setpts=PTS-STARTPTS[head];[main][head]xfade=transition=fade:duration=1:offset=8,format=yuv420p" -an loop.mp4
```

```bash
ffmpeg -i loop.mp4 -an -vf "scale=1920:-2,fps=30" -c:v libvpx-vp9 -b:v 0 -crf 36 -row-mt 1 -pix_fmt yuv420p login.webm
```

```bash
ffmpeg -i loop.mp4 -an -vf "scale=1920:-2,fps=30" -c:v libx264 -preset slow -crf 24 -pix_fmt yuv420p -movflags +faststart login.mp4
```

```bash
ffmpeg -i loop.mp4 -frames:v 1 -vf "scale=1920:-2" -quality 80 poster.webp
```

雾白画面以平滑渐变为主，压缩后容易出现色带。出现时先降低 `crf`；如果体积超标，在转码时加 `noise=alls=4:allf=t`，用细颗粒掩盖色带。
