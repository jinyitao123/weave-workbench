# 销售到项目首个预发布

记录类型：预发布说明。版本：`v0.1.0-rc.4`。适用范围：本总仓的桌面、Weave、Forge与固定ObjectUI客户端组合。

## 交付形式

本版按用户选择提供源码与明确未签名的测试安装包，标记为 GitHub prerelease，不设为 Latest，不发布自动更新清单。macOS安装包未进行Developer ID签名或公证；各附件的实际平台与架构以组合清单为准。

[下载与附件](https://github.com/jinyitao123/weave-workbench/releases/tag/v0.1.0-rc.4)中的 `composition-manifest.json` 记录准确总仓提交、组件来源、构建运行、各平台与文件摘要，`SHA256SUMS.txt`用于校验下载。源码由同一标签提供；安装包须来自该准确提交的成功QA运行。发布是否完成以GitHub预发布项目及附件读回为准，本文不替代产物验证。

已有较早RC标签，因此本版沿用下一编号；这是首个GitHub预发布项目，不宣称首次创建版本标签。旧本机QA包沿用的1.1.17是来源版本序列；本版统一为0.1.0-rc.4，采用直接安装测试，不依赖旧版本自动更新。

## 已验证范围

- 已有员工桌面实走及Forge独立读回覆盖线索转化、报价、合同复核与测试签署、下单条件、销售订单批准、准确立项关联和经理从本人待办启动项目。终点是项目进入进行中。
- 复刻(5)的已提交页面和公共控件修复已整合，包含读取失败与迟到响应保护、取消保护、日期输入、项目类型设置和导航。项目立项及关联入口适配明确已批准订单与原生合资格经理；完整复刻及全部页面业务仍未通过。
- 经理待办已按当前授权来源读取，明确无权的来源不再造成误报，未知权限或有权后的读取失败仍报错。
- Weave包含Claude订阅登录及Windows结果恢复修复，部署在构建与切换前检查磁盘可用空间。容量检查不预留空间，不自动清理、重试或恢复数据库。

当前组件版本仅由[版本锁](../../components.lock.json)和Forge中的Console锁维护。具体检查、失败、实际部署与GUI观察见[环境说明](../environments/开发联调环境.md)、[订单场景](../../scenarios/sales-order-handoff/销售订单闭环场景设计.md)；历史局部证据只适用于原受验来源。

## 固定依赖与限制

ObjectUI在锁定发布依赖下的完整测试、类型、构建和Live隔离测试通过；对ObjectStack开发主线的前向兼容探针存在真实类型差异，包括导出任务类型、导航doc与computed写入提示。该探针不被解释为环境故障，本版不升级到未经兼容的开发主线。准确运行及上游来源见[ObjectUI PR2](https://github.com/jinyitao123/objectui/pull/2)。

并发、回执完全丢失后的未知结果恢复、长期稳定性、Windows断电恢复及ACL边界尚未充分验证。本版不能认定生产准入。完整项目多选、附件、批量成员、部分日历几何和完整页面复刻仍未验收。原生关联表仍有技术关联编号展示，未宣称所有页面均已优化。

项目启动后的采购、出库、交付验收及下游财务不在本版验收范围。Weave管理端仅纳入设计，存在权限、验证提交一致性和环境幂等阻断的候选源码未合入本版。其他独有未完成WIP保全，不由分支整合自动变成已发布能力。

账号、组织连接、岗位权限、已发布团队和模型配置由部署方提供，不随公开安装包携带。本版数据为明确标记的合成测试，未执行真实签署或资金交易。
