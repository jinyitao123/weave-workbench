# 车辆管理逐页复刻记录

## 页面合同

- 页面：`page_vehicle_management`
- RISEMAP：`https://risemap.cn/ops/vehicles`
- Forge：`http://localhost:3001/_console/apps/forge/page/page_vehicle_management`
- 岗位：用车申请人、行政派车人员、车辆管理员、私车补贴经办人
- 主原型：工时组合型
- 页面职责：承接公司用车、私车公用、用车日历、车辆台账和用车统计。

## 2026-09-20 RISEMAP 当前事实

- 标题说明为“公司用车申请、私车公用补贴与车辆台账一体化管理”；顶部四项为可用车辆、用车待审批、本月私车补贴、累计里程。
- 页签依次为公司用车、私车公用、用车日历、车辆台账、用车统计。
- 公司用车列表列为申请编号、申请人、用途/路线、用车时间、里程/人数、派车、状态、操作；私车公用将中部列切换为私家车、里程、补贴方式、金额。
- 公司用车申请为独立表单，包含公司抬头、紧急程度、用车事由、起终点、出发/预计返回、估算里程、乘车人数、同行人员、期望车型、用车方式、指定车辆、关联业务、备注和用车须知。
- 用车日历提供周/月视图、公司/车型筛选、区间单数、预计里程、车辆利用率、时段冲突和状态图例；当前无车辆。
- 车辆台账提供搜索、公司、状态、新增车辆；当前 0 条。统计页包含公司里程、私车里程、补贴金额、申请状态分布、补贴方式占比和车辆台账分布。

## Forge 本轮实现与页面复核

- 已替换通用占位页，落地深蓝车辆主题、四项业务指标、五页签及公司/私车差异列。
- 公司与私车申请均使用标准 Forge 弹窗，覆盖主要必填字段、时间先后、里程和人数阻断，提交后写入 `forge_administration_record` 并回读。
- 日历、台账和统计已按 RISEMAP 信息结构分层；车辆台账新增暂不做成假提交，明确提示需先补齐车辆主数据对象。
- 本轮实时打开并核对 RISEMAP `/ops/vehicles`、`/ops/vehicles/company/new` 与 Forge `page_vehicle_management`；已实测公司/私车页签列切换、申请弹窗、桌面首屏和 640×900 窄屏首屏/弹窗，未见按钮或输入框重叠。空表单提交显示“请选择公司抬头”，未生成测试记录。
