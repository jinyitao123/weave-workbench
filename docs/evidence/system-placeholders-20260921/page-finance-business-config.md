# 财务配置逐页交付合同

## 页面责任

- RISEMAP：`https://risemap.cn/settings/business/finance`
- Forge：`/_console/apps/forge/page/page_finance_business_config`
- 岗位：财务管理员、企业管理员
- 主任务：维护付款方式与多级费用类别，供采购、销售、报销、资金和成本业务选用。
- 主原型：configuration；视觉直接对照 RISEMAP 当前业务设置页。

## RISEMAP 当前事实（2026-09-21 内置浏览器实时读取）

- 页面标题“业务设置 - 财务配置”，顶部展示 13 个业务配置分类标签。
- 左侧财务配置树包含“付款方式”“费用类别”。
- 付款方式区有新增按钮；行内包含启停开关、编辑和删除图标。
- 当前付款方式依次可见：银行转账、支付宝、微信支付、现金、支票、其他、电汇、承兑汇票、在线支付、信用证，均为启用。
- 费用类别支持多级分类；当前可见顶级包含销售费用、项目费用、采购费用、研发费用、行政办公费用、人事费用、财务法务费用，并有新增类别、子级、启停、编辑、删除动作。

## Forge 实现

- 独立页面替换 `page_system_gap`，保留标题、业务分类标签、左侧配置树和右侧办理区。
- Forge 顶级“系统”区域改为“业务设置”，删除系统设置组；平台账号、组织、会话和审计继续由 ObjectStack 原生 Setup 承担。
- `forge_business_setting_option` 持久化设置项，按 `scope + setting_type` 分类，费用类别用 `parent_code` 表示递归层次。
- 付款方式和 2026-09-21 实时页面已观察到的三级费用类别以幂等种子初始化；用户新增记录不被种子删除。
- 新增、编辑、启停和删除均调用真实 CRUD；删除使用标准二次确认，存在子级的类别禁止删除。
- 桌面、侧栏占宽、760px 与 520px 下分别重排；长名称保留省略区域，动作按钮固定宽度。

## 下一步与边界

- 当前付款方式对象已持久化，但历史订单仍保存原文字值；修改配置不会静默改写历史单据。
