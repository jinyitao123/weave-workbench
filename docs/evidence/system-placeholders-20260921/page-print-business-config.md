# 打印管理页面合同

## 范围

- RISEMAP：`https://risemap.cn/settings/business/print`
- Forge：`/_console/apps/forge/page/page_print_business_config`
- 原型：配置型页面
- 岗位：系统业务管理员、单据模版管理员

## RISEMAP 当前事实

- 管理 35 种业务单据，分为采购、销售、仓储、质量、财务、运营、生产七组。
- 四个视图为模版管理、印章/签名、页眉页脚库、打印参数。
- 2026-09-21 实时核对时模版总数 0、启用中 0、覆盖 0/35、未配置 35；支持导入全部预置模版、新建模版和针对单据导入标准版或空白创建。

## Forge 实现

- 已替换原 `page_system_gap` 占位入口，提供同样的 35 种单据目录、四个配置视图与四项汇总指标。
- 模版及其他打印配置持久化到 `forge_business_setting_option` 的 `print` 范围，支持新增、编辑、启停、删除与重启回读。
- 一键导入当前提供采购订单、销售合同、出库单三类标准版模版，并且不覆盖已有同名配置。

## 明确差异

- 当前快速交付未实现可视化模版画布、字段拖拽和真实 PDF 渲染；现阶段完成的是配置目录、模版主数据与入口清理。
- 同视口截图、叠图及量化像素差未执行，保持 `review_required`。
