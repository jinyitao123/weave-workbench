# 图纸配置页面合同

## 范围

- RISEMAP：`https://risemap.cn/settings/business/drawing`
- Forge：`/_console/apps/forge/page/page_drawing_business_config`
- 原型：配置型页面
- 岗位：图纸管理员、研发管理人员

## RISEMAP 当前事实

- 页面包含图纸类型、图纸分类、变更类型、变更等级、版本类型、评审分类、参与人角色、问题分类、问题严重度、保密等级十类配置。
- 每类按名称、排序、备注、状态展示，并提供新增、编辑、删除与启停动作。
- 2026-09-21 实时核对时，变更等级、参与人角色、保密等级为空；其余七类的当前默认项已作为 Forge 首次启动种子记录。

## Forge 实现

- 十类配置均可切换、搜索、刷新，并支持新增、编辑、删除和启停。
- 数据写入 `forge_drawing_business_setting`，按分类隔离；默认数据仅首次写入，后续重启不会覆盖租户修改。
- 删除使用带不可恢复提示的二次确认；历史业务引用不由本页自动改写。
