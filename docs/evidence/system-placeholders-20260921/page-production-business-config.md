# 生产配置页面合同

## 范围

- RISEMAP：`https://risemap.cn/settings/business/production`
- Forge：`/_console/apps/forge/page/page_production_config`
- 原型：配置型页面
- 岗位：生产管理员

## RISEMAP 当前事实

- 页面仅包含拆解原因和改制原因两类配置。
- 原因可新增和启停；停用后不再进入新单据下拉，历史单据仍显示原原因。
- 2026-09-21 实时核对时，拆解原因为空；改制原因包含“质量返修”，说明为“成品保留库存，仅更换不合格内部零部件”。

## Forge 实现

- 两类原因均支持搜索、新增、启停和刷新，并使用认证适配器访问当前数据源。
- 原因会联动拆解单与换件单的新建下拉；已保存单据保留原因文字快照。
- 当前数据库已有与 RISEMAP 同名同说明的“质量返修”配置，停服重启后可回读。
