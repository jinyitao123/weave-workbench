# 财务总览占位清理记录

## 页面合同

- pageId：`page_finance_overview`
- stateId：`live-finance-overview`
- RISEMAP 入口：`https://risemap.cn/finance/statistics/overview`
- Forge 入口：`/_console/apps/forge/page/page_finance_overview`
- 页面职责：用同一期间口径汇总经营金额、往来余额、库存、资金、固定资产与待处理财务风险，并提供资产负债视图。
- 岗位：财务负责人、经营负责人、应收应付会计、资金会计。
- 主单据：销售订单与合同、采购订单、收付款流水、应收应付、库存余额、资金账户、固定资产、预收预付。
- 主原型：`analysis`；实现参考 `inventory-statistics.page.ts` 与共享 `product-ui.ts`，业务内容和几何以 RISEMAP 当前页为准。
- 首屏区块顺序：标题与双导出 → 经营总览/资产负债页签 → 期间筛选与统计口径 → 当前经营余额 → 业务金额总览 → 业务金额对比与执行进度 → 经营表现与判断 → 资金结构 → 待处理事项；资产负债页签为四项指标 → 资产结构与判断 → 资产负债明细。
- 主动作：切换视图、切换统计期间、导出当前视图、切换待处理风险类型、进入对应财务明细。
- 来源关系：销售订单/合同形成期间经营规模；收付款流水及预收预付形成资金与回款；应收应付形成往来余额和到期风险；库存余额与固定资产形成资产结构。
- 下一步入口：应收应付、资金账户、银行流水、固定资产、库存统计。
