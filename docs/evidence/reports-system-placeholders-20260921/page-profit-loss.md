# 损益分析占位清理记录

## 页面合同

- pageId：`page_profit_loss`
- stateId：`live-profit-loss`
- RISEMAP 入口：`https://risemap.cn/finance/statistics/profit`
- Forge 入口：`/_console/apps/forge/page/page_profit_loss`
- 页面职责：在统一期间内查看收入、成本费用、项目盈利、合同签约和人力资源支出，并下钻到项目与合同明细。
- 岗位：财务负责人、经营负责人、项目负责人、人力成本负责人。
- 主单据：销售合同、收入确认、应收账款、项目、项目成本池、项目费用、项目工时、项目结算。
- 主原型：`analysis`；工程参考 `project-timesheet-cost.page.ts` 与共享 `product-ui.ts`，页面结构和视觉以 RISEMAP 当前页为准。
- 首屏区块顺序：标题与双导出 → 五个分析页签 → 期间筛选与统计口径 → 四项指标 → 趋势/构成 → 明细或空态。
- 主动作：切换分析页签、切换统计期间、导出当前视图；本页不新增业务单据。
- 来源关系：已审核收入确认形成收入；项目成本池与已通过报销形成成本；项目汇总收入和成本形成毛利；销售合同形成签约统计；已审核工时形成当前 Forge 人力成本口径。
- 下一步入口：收入确认、项目费用与成本归集、项目工时、销售合同。
