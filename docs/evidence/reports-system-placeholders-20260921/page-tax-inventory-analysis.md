# 税务库存占位清理记录

## 页面合同

- pageId：`page_tax_inventory_analysis`
- RISEMAP 入口：`https://risemap.cn/finance/statistics/budget-tax`
- Forge 入口：`/_console/apps/forge/page/page_tax_inventory_analysis`
- 页面职责：展示进销项发票与税额，以及库存资金、周转、呆滞和资金占用。
- 岗位：税务会计、库存会计、财务负责人、经营负责人。
- 主单据：销项发票及明细、进项发票及明细、库存余额、库存流水、应收应付。
- 主原型：`analysis`；以 RISEMAP 当前税务库存页面为直接结构基线。
- 首屏顺序：标题及导出 → 发票分析/库存资金 → 期间筛选 → 实时汇总说明 → 四项指标 → 趋势与结构或高占用物料。
