# 资金分析占位清理记录

## 页面合同

- pageId：`page_fund_analysis`
- RISEMAP 入口：`https://risemap.cn/finance/statistics/capital`
- Forge 入口：`/_console/apps/forge/page/page_fund_analysis`
- 页面职责：按统计周期展示现金流、未来 30 天资金预测和启用资金账户余额。
- 岗位：资金会计、财务负责人、经营负责人。
- 主单据：资金账户、实际收款、实际付款、应收、应付。
- 主原型：`analysis`；以 RISEMAP 当前资金分析页面为直接结构基线，并复用 Forge 财务总览的响应式分析组件。
- 首屏顺序：标题及导出 → 现金流/资金预测/账户余额 → 期间筛选 → 实时汇总说明 → 四项指标 → 趋势、构成或账户明细。
- 主动作：切换视图和统计周期、打开指标口径说明、导出、进入资金账户。

## 2026-09-21 RISEMAP 当前事实

- 已在登录态内置浏览器通过“报表 → 财务统计 → 资金分析”进入当前页，真实 URL 为 `/finance/statistics/capital`；旧猜测 `/finance/statistics/fund` 会回到工作台，不能作为页面证据。
- 标题为“资金分析”，说明为“现金流、资金预测和账户余额分析”，标题动作是“导出PDF”“导出Excel”。
- 三个视图为现金流、资金预测、账户余额；筛选当前为本季度，页面说明财务数据按业务单据实时汇总，并显示统计周期。
- 现金流显示期末现金余额、本季度流入、本季度流出、净现金流，以及现金流入/流出趋势和现金流构成。
- 资金预测显示当前可用资金、待回收应收、30天内应付、预测资金余量，以及未来30天资金到期结构；当前线上 30 天内应付为 `36,720.00`，其余资金指标为零。
- 账户余额显示账户余额、本季度资金流入、本季度资金流出、资金净变动、账户资金趋势和“查看资金账户”。

## 修改前 Forge 差异与实现边界

- 修改前导航指向通用 `page_reports_gap`，只展示报表入口目录，没有任何资金指标、筛选、三视图、口径说明或业务数据。
- Forge 实现直接读取当前持久库的启用资金账户、实际收付款、未结应收应付；取消、作废、撤销、驳回和草稿不计入有效现金流。
- 资金预测仅使用现有到期日做未来 30 天简单预测，属于 Forge 可复核计算；不把尚不存在的预算、融资或投资数据推断为 RISEMAP 事实。

## 验收状态

- 当前状态：`review_pending`；通用入口目录已替换为独立资金分析页。
- Forge 真实数据：同一持久库当前有 `0` 个启用资金账户、`0` 笔有效收款、`0` 笔有效付款、`0` 笔未结应收、`0` 笔未结应付；页面按事实显示零值，不注入演示余额。
- 页面操作：内置浏览器依次切换现金流、资金预测、账户余额；打开“期末现金余额计算说明”标准弹窗并关闭；统计期间由本季度切换到本月，页面周期和指标文案同步变化，再恢复本季度。
- 页面结构：现金流包含四项指标、三个月流入/流出趋势与现金流构成；预测包含四项指标和未来 30 天到期结构；账户余额包含四项指标、账户明细及真实空态。
- 几何体检：同一真实数据状态检查 `1440×900`、`900×776`、`760×776`。三档均无按钮、选择器或帮助控件重叠，页面 `scrollWidth` 与视口宽度一致。`900px` 时四张指标卡按两列重排；`760px` 时标题动作各占半行、期间选择器宽 `709px`、四张指标卡单列，均未发生互相挤压、文字竖排、越界或异常收缩。
- 持久化：本页只读汇总；完整停止服务并使用同一 `.objectstack/forge.sqlite` 重启后，数据集成脚本仍回读相同的真实零值。
- visual：`partial`，已完成同视口实时观察、元素级量化和三档几何核查；内置浏览器当前接口不能把已登录 RISEMAP 截图字节保存为仓库证据，因此没有伪造固定裁剪叠图，仍缺 RISEMAP/Forge 原图、叠图和逐像素差值文件。
- interaction：`partial`，Forge 三视图、期间筛选、口径弹窗均通过；未在 RISEMAP 执行导出文件内容核对。
- business：`partial`，两侧不是同一组资金账户与往来材料，RISEMAP 线上预测应付 `36,720.00` 不能移植为 Forge 数据。
- review：保持 `review_required`，不得表述为像素级验收通过。
