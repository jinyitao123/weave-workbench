# 库存统计占位清理记录

## 页面合同

- RISEMAP 入口：`https://risemap.cn/reports/inventory`
- Forge 入口：`/_console/apps/forge/page/page_inventory_statistics`
- 页面职责：按物料、仓库和时间范围查看库存金额、SKU、低库存、周转、库龄及排行。
- 岗位：仓库负责人、供应链主管、经营分析人员。
- 主数据与单据：库存余额、库存流水、仓库、物料规格、物料和分类。
- 主原型：分析型；参考 `project-timesheet-cost.page.ts` 与共享 `product-ui.ts`。
- 主动作：筛选物料/仓库/周期、刷新、导出当前库存、进入仓库/到货/检验业务页。

## 2026-09-21 RISEMAP 当前事实

- 标题为“库存统计”，说明覆盖库存金额、库存周转、呆滞物料与安全库存预警。
- 页签为库存统计、仓库统计、到货统计、检验统计。
- 筛选包含物料编码/名称/仓库搜索、仓库范围、日期周期和刷新。
- 指标包含库存金额、库存 SKU、低库存和周转率；分析区包含库存金额趋势、数量趋势、库龄健康度、出库排行、呆滞排行和分类占比。
- 本次取证显示库存金额 80283.19、库存 SKU 5 个、低库存 0 项、周转率 0.3 次；只记录 RISEMAP 当前材料。

## Forge 实现边界

- `inventory_statistics` 已从 `page_reports_gap` 独立为 `page_inventory_statistics`。
- 页面读取库存余额、库存流水、仓库、物料规格、物料和分类的当前数据。
- 库存金额、低库存、周转率、库龄、出库排行、呆滞排行和分类排行均由当前 Forge 账面数据计算。
- 历史库存金额由当前余额按后续入出库流水反推，不把当前值重复伪装成历史快照。
- 维度按钮进入现有库存总览、仓库、到货和检验页面，不保留假按钮。
