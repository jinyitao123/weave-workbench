## 本次新增边界

当前最小新建流程由 Workbench Host 调用 Weave 现有智能体和团队接口，创建两个可编辑初始成员后建立团队；团队建立失败会尝试回收本次成员。服务端原子创建向导仍是后续增强，不阻塞当前 MVP1 开发者从空组织开始配置。

成员草稿现已具备“保存草稿”和“应用配置”两个明确动作；应用后会生成成员新版本并保留可继续编辑的基线。流程版本已经完成检查、发布和下一版草稿迭代。内联技能是否进入冻结运行包、并行团队执行和 Forge 业务结果写回仍未通过，因此本轮仍未将端到端流程记为完成。

## 本机连接事实

当前 Mac 的网络代理将公网 `8080` 请求路由到虚拟地址后关闭连接，服务端没有收到请求。联调桌面因此通过 SSH 将本机 `127.0.0.1:18080` 转发到服务器 `127.0.0.1:8080`，并用 `WORKBENCH_WEAVE_URL=http://127.0.0.1:18080` 启动。该转发只解决当前开发机链路，不改变客户内网部署地址或服务边界。
